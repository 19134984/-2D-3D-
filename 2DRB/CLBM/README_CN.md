# 二维均匀网格 CLBM / CTLBM

本目录实现 Sharma、Straka、Tavares 的 2018 年论文 *Natural convection heat transfer modeling by the cascaded thermal lattice Boltzmann method*，DOI：[10.1016/j.ijthermalsci.2018.08.033](https://doi.org/10.1016/j.ijthermalsci.2018.08.033)。流场为 D2Q9 级联中心矩模型，温度为该文 D2Q5 CTLBM；支持封闭侧热腔和封闭 Rayleigh–Bénard 腔，当前只做二维均匀网格。求解器为单 GPU OpenACC 版本，没有 MPI 或 OpenMP 执行路径。

## 文件与使用

- `2DRBOpenaccCLBM.F90`：完整独立源文件。
- `verify_clbm_local.py`：编译实际源文件的临时小网格副本，核验数学恒等式、导热、输出和严格续算。
- `validation_local.json`：本次本地检查结果及被测源文件 SHA-256。
- `PROVENANCE.json`：论文、基线和本次衍生源文件的来源记录。
- `公式消歧_CN.md`：原文式(30)、温度参数和边界公式的处理依据。

默认开启 `steadyFlow` 和 `SideHeatedCell`，即侧热稳态。改做 RB 时，在文件开头注释这两个宏，并开启 `unsteadyFlow` 和 `RayleighBenardCell`；边界宏随算例自动配套。两者均为四壁无滑移，侧热为左右恒温、上下绝热，RB 为上下恒温、左右绝热。

主要参数直接写在 `commondata`，沿用原有 Fortran 风格及中文说明。默认 `nx=ny=256`、`Rayleigh=1e6`、`Prandtl=0.71`、`Mach=0.05`、`Thot=1`、`Tcold=0`。网格、Ra、Pr、Ma、稳态阈值、输出间隔、RB 目标时长及平均窗口均可直接修改。侧热初值沿用现有框架的线性导热温度；RB 为导热态加确定性小扰动。

## 实现范围

主程序、数组顺序、稳态误差、Nu/Re、壁面与中心线极值、流函数/涡量、Tecplot、二进制快照及统计输出延续本项目基线。二维公式和后处理参照 `均匀网格/2DRBOpenmp.F90`，OpenACC 常驻数据区、异步循环及主机同步参照 `均匀网格/2DRBOpenacc.F90`。本次同时生成的 FPC 源文件仅用于复用已经整理的共同程序框架和输出/续算修复；这里重新实现了整套 CLBM 碰撞和温度边界，没有使用 FPC 的高阶吸引子或源项。

方向顺序保持本项目的 `0` 静止、`1` 东、`2` 北、`3` 西、`4` 南、`5` 东北、`6` 西北、`7` 西南、`8` 东南。数组为 `f(i,j,alpha)`、`g(i,j,alpha)`，温度方向只到 `4`。

- 流场二阶迹与二阶差分别控制体积黏性和剪切黏性，三阶率由原文式(19)确定，四阶平衡态固定为 `rho*cs2**2`。
- 流场采用原文式(5)–(7)的去混叠强迫项，中心源只有两个一阶分量。宏观速度含 `F/2`，初始化也按同一去混叠定义构造存储分布。
- 温度碰撞直接实现原文式(27)的四个 `q`。它的二阶中心平衡态随 `u**2`、`v**2` 变化，不能直接替换成另一篇 Fei 模型的恒定 `cT**2*T`。
- 温度不叠加旧 D2Q5 MRT、`useG`、滤波、正则化或额外热源。
- 主循环同步为：两个碰撞读取同一时刻宏观场，再完成两套迁移/边界，最后恢复温度与含新浮力的速度。

原文存在需要公开说明的参数/排印不一致。本实现保留其字面 `thermalA=sqrt(2/5)`、`thermalCs2=thermalA/2` 和式(27)；二阶热矩的松弛率使用按实际权重独立推导的半程 ABB 零滑移关系。该处理详见 `公式消歧_CN.md`，因此不能声称逐字照抄原文参数就已经重现其全部数值表格。

## 输出与续算

输出使用独立的 `...CLBM...` 前缀。稳态保存误差、最终 Nu/Re 和剖面诊断；非稳态按指定间隔保存 Nu/Re 时间序列与快照，结束后对用户指定时间窗口计算统计结果。不整除采样间隔的终止时刻不会伪造额外样本。

`loadInitField=1` 时要求匹配本程序的 latest 元数据、检查点和历史文件。检查点标识为 `CLBM2D_D2Q9_D2Q5_V1`；元数据版本为 `701`，记录网格、模式、算例、17 个物理/时间轴参数和样本数。旧 MRT、FPC、不同网格或不兼容物理参数的检查点会被拒绝。正常续算可以增加目标时长，不能用旧状态更改 Ra/Pr/Ma 后假装连续运行。

## 本地验证与限制

运行 `python verify_clbm_local.py` 可复查。脚本在临时目录构造小网格副本，不修改主文件中的正式参数；默认使用本机 MSYS2 的 gfortran，并启用 OpenACC host、数组越界检查及浮点异常捕获。

已检查的内容包括离散矩定义与变换互逆、密度和温度守恒、完整浮力动量增量、去混叠初值、Sharma 热碰撞的二阶目标、两种几何下的线性导热和 Nu=1、带源抛物导热的 ABB 零滑移，以及侧热/RB 的有限步输出和严格重启。完整 48 步与 32 步加续算 16 步的 f/g 及共同采样时刻快照需要逐位一致；采样间隔设为 7 步以覆盖不整除的终止时刻。

这些是实现层面的开发核验。尚未验证 NVIDIA GPU 编译/执行、论文稳态基准、RB 长时间统计、高 Ra 稳定性或网格独立性。本次没有访问服务器，也没有提交任务。
