# 教学结构设计审查

- **审查角色：** 基础与教学智能体
- **审查方式：** 只读
- **证据范围：** 只依据四篇核心 PDF
- **文件操作：** 审查阶段未修改源文件
- **用途限制：** 本备忘录是设计输入，不替代论文逐页证据账本，也未读取或引用旧高级报告、旧推导程序或旧测试。

## 1. 审查问题

四篇核心论文能否直接构成零基础教程？如果不能，必须先补哪些教学依赖，才能让第一次接触 population、矩、松弛率、TRT 与等效方程的读者逐步跟上两条主线？

## 2. 四篇论文可直接提供的内容

### Wang 2013

- PDF pp. 2–4 给出 D2Q9 流场、D2Q5 温度场、矩变换、平衡矩和碰撞矩阵；
- Eq. (17) 给出 D2Q5 四阶各向同性关系；
- Eqs. (18)–(20) 给出特殊碰撞率，但省略了零基础读者需要的中间推导；
- PDF pp. 5–6 给出速度 BB、温度 ABB 和绝热 BB 的应用形式。

### Contrino et al. 2014

- PDF pp. 2–4 给出 D2Q9+D2Q5 模型；
- Eq. (17) 是四阶各向同性条件；
- Eq. (18) 是消除论文所显示完整四阶项还需要的进一步关系；
- Eqs. (19)–(20) 给出特殊 TRT 参数点；
- 论文明确指出 D2Q5 不能同时消除三阶误差和四阶误差。

### Dubois–Lallemand

- PDF pp. 2–5 给出 Boltzmann 方程、population、矩、碰撞、迁移、BGK/MRT，以及 `sigma_k=1/s_k-1/2`；
- PDF pp. 7–9 给出高阶 Taylor 递推框架，但默认读者已有较强背景；
- PDF p. 11 Eqs. (39)–(42) 给出 D2Q5 和 `kappa_40,kappa_22`；
- PDF p. 16 Eq. (55) 给出四阶误差完全消除条件；加入 TRT 约束后得到正支特殊点 `H_1=1/sqrt(12)`、`H_3=H_4=1/sqrt(3)`；
- PDF p. 17 给出平面波验证。

### Ginzburg–d'Humières

- PDF pp. 1–2 解释未知入射 population、Knudsen 层、表观滑移和有效壁面位置；
- PDF pp. 4–7 给出 link closure 与 Taylor 分析；
- Eq. (41) 定义论文归一化的 `Lambda^2`；
- Eqs. (42)–(43) 在受限 halfway Poiseuille/Couette 场景给出 `Lambda^2=1/4`，换算为未缩放 Hénon 乘积 `H_even H_odd=3/16`。

## 3. 四篇论文默认但零基础读者缺少的依赖

四篇核心论文不能直接承担以下入门教学，需要在引用论文公式之前另设背景章节：

1. 偏导数、梯度、散度、拉普拉斯算子、四阶导数和大 `O` 记号；
2. 扩散、对流—扩散方程以及 Dirichlet、Neumann、无滑移、绝热边界的物理含义；
3. population、碰撞、迁移、平衡态和宏观量重构；
4. D1Q3、D2Q5、D2Q9 的方向、权重和反向方向；
5. 矩作为 population 加权和，以及矩阵换坐标的具体含义；
6. BGK/TRT/MRT 层级和 `碰撞率 r / 松弛时间 tau / Hénon 参数 H` 的区别；
7. 反向 population 的奇偶分解；
8. BB、ABB、halfway 几何和有效壁面位置；
9. Taylor modified equation、轴向/混合四阶导数、各向同性与误差为零的区别；
10. 论文同名异义：Wang/Contrino 的 `sigma` 是碰撞率，Dubois 的 `sigma` 是 Hénon shift。

这些内容可由单独标记的权威背景来源补足，但背景来源禁止替代四篇核心 PDF 对 magic 和四阶参数的证据。

## 4. 建议的依赖顺序

> PDE 基础 -> D1Q3 数值 population -> 碰撞/迁移/重构 -> D2Q5/D2Q9 -> 具体求矩 -> 平衡与守恒 -> BGK -> Hénon shift -> 奇偶分解 -> TRT/MRT -> BB/ABB/halfway -> Ginzburg 边界 magic -> modified-equation 热身 -> D2Q5 矩阵 -> 二阶扩散 -> 四阶系数 -> 四阶各向同性 -> 四阶完全消除 -> TRT 特殊点 -> Wang/Contrino 映射 -> 限制与未证明事项

这条顺序应保持“先共同基础、后分双主线”：边界主线讨论受限 D2Q9 halfway BB 的 `3/16`；温度主线讨论 D2Q5 体相四阶各向同性的 `1/6`。两者在综合章之前不得合并讲成一个 magic 常数。

## 5. 教学验收建议

- 第一处 LBM 公式之前先解释 population，并给 D1Q3 数字例子；
- 第一处矩公式之前先手算一个加权和；
- 第一处 TRT 公式之前先解释 BGK、`r/tau/H` 和奇偶分解；
- 第一处边界 magic 常数之前先定义墙面 link、未知入射 population 和边界残差；
- 第一处四阶条件之前先完成简单差分的 Taylor 展开与 modified equation 热身；
- 每节结尾写明“已经知道什么、还不知道什么”；
- 每个核心关系同时写来源、逐步中间推导和不可外推边界。

## 6. 设计结论

四篇论文足以限定两条核心证据链，但不足以直接充当零基础教材。批准采用设计规格中的“双主线零基础课程”，前提是背景内容单独标源、核心公式回到四篇 PDF、所有跨论文记号先做映射，并由禁止跳步审查逐章验收。
