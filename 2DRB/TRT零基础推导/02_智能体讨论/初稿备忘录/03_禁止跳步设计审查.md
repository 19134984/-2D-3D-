# 禁止跳步设计审查

- **审查角色：** 禁止跳步智能体
- **审查方式：** 只读
- **证据范围：** 只依据四篇核心 PDF
- **文件操作：** 审查阶段未修改源文件
- **用途限制：** 本备忘录规定后续推导的验收门槛，不新增论文结论，也未读取或引用旧高级报告、旧推导程序或旧测试。

## 1. 等式分类

每个等号附近必须说明它属于哪一类：

1. 定义；
2. 精确代数恒等式；
3. 建模选择；
4. 近似；
5. 渐近等式；
6. 参数约束；
7. 特殊情形。

不得用同一种排版把定义、近似和特殊参数选择混成看似同等强度的“公式”。

## 2. 新符号登记

每个新符号在首次出现前必须说明：

- 数学类型（标量、向量、矩阵、算子或索引）；
- 物理意义；
- 单位、格子单位或无量纲性质；
- 取值范围和非零/正值等条件；
- 属于流场还是温度场；
- 对应守恒量还是非守恒模态；
- 第一次在后文用于哪一步。

碰撞率、松弛时间和 Hénon 参数必须分别写成 `r`、`tau=1/r`、`H=1/r-1/2`，禁止沿用含义不明的裸 `sigma`。

## 3. 每段推导的最小闭环

每段推导必须给出：

1. 起点；
2. 目标；
3. 全部代入、展开、求和、消元、约分和抵消；
4. 每个分母非零的条件；
5. 量纲或格子单位检查；
6. 至少一个极限检查或回代检查。

从式 A 到式 B 若包含两次以上代数操作，必须写出中间式。禁止用“显然”“类似可得”“经过简单计算”“化简后”等词跳过关键步骤。

## 4. 温度四阶主线的强制节点

1. 把应用论文碰撞率重命名为 `r_kappa,r_e,r_nu`；
2. 原样登记 Dubois–Lallemand 的 `kappa_40,kappa_22`，并标明来源页码和式号；
3. 展开二维双调和算子，逐项导出轴向项与混合项的各向同性比例；
4. 完整计算 `kappa_22-2kappa_40`，逐步推出 `H_kappa H_nu=H_1H_4=1/6`；
5. 分别令两个四阶系数为零，消元并推导 Eq. (55)，不得把各向同性条件当作完全消除条件；
6. 把 Eq. (55) 逐行换回碰撞率形式；
7. 加入 TRT 约束 `H_e=H_nu`，求解正支，并声明分支选择和分母条件；
8. 把特殊参数分别代回 `kappa_40` 和 `kappa_22`，逐个验证为零。

完成第 4 步只证明 D2Q5 四阶各向同性；完成第 8 步也不能自动证明全局四阶，因为三阶项和边界误差仍需单独检查。

## 5. 边界主线的强制节点

1. 定义壁面、流体节点、固体节点、link 方向，以及迁移后已知/未知 population；
2. 写出 BB 闭合关系，并说明 halfway wall 的几何位置；
3. 在边界处逐项 Taylor 展开 population；
4. 明确引入受限 Poiseuille/Couette 型剖面和动量方程；
5. 从边界残差推导有效宽度或有效壁面位置；
6. 先施加精确 halfway 位置，再推出 `Lambda^2=1/4 <-> H_even H_odd=3/16`；
7. 列出稳态线性/Stokes、均匀力、平直网格对齐墙面、halfway BB 和 forcing gauge 等全部限制，并写明尚未解决的场景。

禁止在推导有效位置之前直接展示 magic 常数，也禁止把 `3/16` 与 D2Q5 体相各向同性的 `1/6` 拼成同一条参数链。

## 6. 红线

以下概念不得混同：

- `rate / tau / H`；
- 四阶各向同性 / 四阶系数为零 / 整体四阶精度；
- D2Q5 / D2Q9；
- 体相误差 / 边界误差；
- 受限平直墙面 magic / 普适边界精度；
- 符号推导证明 / 数值实验支持。

一旦出现任一混同，禁止跳步智能体有权退回整节，直至作者补齐定义、假设和中间式。

## 7. 章节审查流程

> 作者推导 -> 符号/来源审查 -> 独立代数复算 -> 零基础/禁止跳步审查 -> 作者回应 -> 第二次独立复算 -> 冻结章节

任何单个智能体的答案都不能直接进入最终报告。复算者必须能够只凭本章列出的原文输入重新得到结论；如果做不到，该章保持“未通过”或把命题标为“未证明”。
