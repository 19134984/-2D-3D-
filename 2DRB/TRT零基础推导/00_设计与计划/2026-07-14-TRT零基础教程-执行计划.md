# TRT magic 参数与温度四阶误差零基础教程 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 只依据四篇指定核心 PDF 推导 boundary magic 与 D2Q5 温度四阶误差消除，并用权威网络资料补齐零基础前置知识，交付可从头跟算的中文 Markdown/PDF 教程及完整审查记录。

**Architecture:** 把工作拆成“来源证据、共同基础、BGK 到 TRT、边界 magic、温度四阶误差、参数映射、综合应用、交叉审查、最终装配”九个边界清晰的单元。核心公式先由论文证据智能体登记，再由主推导智能体补足中间代数，最后由独立复算者和禁止跳步智能体复核；主智能体只依据四篇 PDF 与可重复代数裁决冲突。

**Tech Stack:** Markdown + LaTeX 数学、Poppler/pdftotext、Pandoc + XeLaTeX、Python/SymPy 精确代数、SVG/PNG 教学图、Git、多智能体交叉审查。

## Global Constraints

- 用户是完全没有 LBM 基础的读者；正文不得默认 population、矩、松弛率、TRT 或 modified equation 已知。
- magic 参数与温度四阶消除的核心来源仅限四篇指定 PDF。
- `docs/lbm-cde-trt-derivation.md`、`docs/derivation/`、`tools/derivation/`、`tests/derivation/` 及其结论不得作为来源或母本。
- 联网资料只补基础概念，必须保存原始检索结果和 URL，并标为“背景来源”。
- 每个新符号先定义；每个等号说明操作；每个近似说明小参数、阶数与舍弃项。
- 碰撞率、松弛时间与 Hénon 参数必须使用不同符号；跨论文映射必须显式列出。
- D2Q9 流场 boundary magic、D2Q5 温度四阶各向同性和 D2Q5 四阶完全消除必须始终分开。
- 任何子智能体的单独结论不得直接进入最终报告。
- 全部新文件保存在 `TRT零基础推导/`；不修改生产 Fortran 求解器。
