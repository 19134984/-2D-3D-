# TRT magic 参数与温度四阶误差零基础教程：设计规格

**日期：** 2026-07-14  
**状态：** 用户已批准  
**目标读者：** 完全没有 LBM 基础、第一次接触 population、矩、松弛率、TRT 与等效方程的学习者

## 1. 目标

从最基础的物理、数学和 LBM 概念开始，逐步解释并推导两条彼此相关但不能混同的主线：

1. TRT 中的边界 magic 参数如何产生，它怎样控制受限场景下的边界位置误差或表观滑移；
2. D2Q5 温度模型的四阶误差从哪里产生，怎样区分四阶各向同性与四阶误差完全消除，以及 Wang 和 Contrino 等（2014，本地文件名含 `Luo2014`）为什么采用特定参数。

最终报告必须让读者能够回答：

- population、碰撞、迁移、平衡态和矩分别是什么；
- BGK、MRT、TRT 的关系是什么；
- 碰撞率、松弛时间、Hénon 参数和不同论文中的 `sigma` 分别是什么；
- bounce-back、anti-bounce-back、halfway wall 和边界滑移是什么；
- `1/4` 与 `3/16` 为什么是同一个受限边界条件的两种归一化写法；
- D2Q5 温度四阶各向同性的 `1/6` 为什么属于另一类问题；
- modified equation 和四阶导数误差项是什么；
- 四阶各向同性为什么不等于四阶误差完全消除；
- D2Q5 的温度四阶参数为什么不能不加证明地移植到 D2Q9 或其他模型。

## 3. 教学组织方案

采用“双主线零基础课程”，不按四篇论文逐篇翻译。

共同基础链为：

> 连续物理问题 -> 离散 population -> 碰撞与迁移 -> 格子与矩 -> BGK -> Hénon 参数 -> 奇偶分解 -> TRT

边界主线为：

> 未知入射 population -> bounce-back/anti-bounce-back -> halfway wall -> 离散边界残差 -> 有效壁面位置/滑移 -> magic 条件

温度四阶主线为：

> Taylor 展开 -> modified equation -> D2Q5 矩模型 -> 二阶扩散率 -> 三/四阶项 -> 四阶各向同性 -> 四阶完全消除 -> Wang/Contrino 参数映射

最后把两条主线并排比较，说明它们控制的误差对象、推导假设、参数组合和适用范围不同。

## 5. “不允许跳步骤”的写作规则

每一章必须遵守：

1. 新符号在第一次出现前定义，并说明单位或无量纲性质；
2. 新术语先用自然语言解释，再给数学定义；
3. 每个等号说明使用了哪一步操作：代入、展开、求和、消元、约分或近似；
4. 一次最多引入一个新思想；
5. 从式 A 到式 B 若需要两次以上代数操作，必须写出中间式；
6. 每个近似都列出假设、小参数和被舍弃项；
7. 每个参数关系同时给出 rate、relaxation time 与 Hénon shift 版本；
8. D2Q5、D2Q9、流场模型与温度模型必须显式标注，禁止暗中移植；
9. “各向同性”“四阶项为零”“整体四阶精度”必须分开定义；
10. “magic”必须说明控制对象和有效场景，禁止写成脱离模型的常数；
11. 每节结尾加入“这一节已经知道什么、还不知道什么”；
12. 每章加入至少一个具体数字或小矩阵手算示例；
13. 长推导同时提供逐步正文和紧凑复核框；
14. 每个核心结论给出来源页码/式号和不可外推边界。

## 6. 来源标记

正文中的关键内容采用四类标记：

- **原文公式：** 直接来自四篇核心 PDF，记录论文、印刷页/PDF 页和式号；
- **中间推导：** 为补足论文省略步骤而进行的独立代数；
- **背景补充：** 来自联网权威资料的入门概念；
- **适用范围：** 列出结论成立的几何、方程、格子、边界、forcing、归一化和小参数假设。

所有引用和推导登记在证据矩阵中。无法从原文或独立代数闭环的命题必须标为“未证明”，不得用肯定语气进入结论。

## 7. 多智能体互审设计

最多并行使用三名子智能体，由主智能体统一裁决：

- **基础与教学智能体：** 构建零基础概念链、数值小例子和术语解释；
- **原文与公式智能体：** 核对四篇 PDF 的页码、式号、符号、归一化和推导输入；
- **禁止跳步智能体：** 专门审查每个等号、定义、假设和模型映射，拥有退回章节的否决权。

每个核心章节执行五轮：

1. 独立提取原文证据；
2. 主推导者写出逐步推导；
3. 另一智能体不看答案独立复算关键关系；
4. 禁止跳步智能体逐项审查；
5. 主智能体根据原文和复算结果解决冲突并记录决定。

任何单个智能体的结论都不能未经交叉审查进入最终报告。
