                                                           Supplementary material:
                                                           Nature of problem: DUGKS-GPU is an advanced numerical code designed to accelerate the simulation of turbulent
                                                           ﬂuid ﬂows through the application of the kinetic method known as the Discrete Uniﬁed Gas Kinetic Scheme
                                                           (DUGKS). This computational tool comprises a CUDA Fortran version, tailored for a single GPU, as well as a
                                                           CUDA C++ version developed for multi-GPU platforms.
                                                           Solution method: The code employs a second-order ﬁnite-volume discretization of the discrete velocity Boltzmann
                                                           equation with the BGK collision model. It can be used to simulate small to medium-scale problems on modern
                                                           multi-GPU platforms with CUDA architecture.
