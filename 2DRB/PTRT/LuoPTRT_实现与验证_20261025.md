# Luo + P-TRT 二维非稳态 RB 独立副本

主源码：`PTRT/2DRBOpenaccLuoPTRT.F90`。母版：
`Xs/D2Q9TRT_D2Q5LuoTRT/2DRBOpenaccLBMCDE_D2Q9TRT_D2Q5LuoTRT.F90`。
母版、均匀网格基线及多块主程序均只读，校验记录在
`运行脚本/run_cases/LuoPTRT_Ra9_Ra10_20261025/protected_sources.json`。

本次明确采用用户修正后的 **1024² / 2048² 流体节点**，Pr=0.7、Ma=0.1、
从零推进 1000 t_ff。上下无滑移恒温、左右无滑移绝热、原线性导热初场，
没有另加扰动。不会读取旧 Luo、MRT 或旧 PTRT 检查点。

## 原有实现与任务书的映射

| 任务书 Luo 顺序 | 当前代码顺序 | 含义与位置 |
|---|---|---|
| 0 | `m(0)` | `sum(f)=delta_rho`，`rho=rho0+sum(f)` |
| 1 | `m(3)` | 原始 x 动量 `jx` |
| 2 | `m(5)` | 原始 y 动量 `jy` |
| 3 | `m(1)` | 二阶能量矩 `e` |
| 4 | `m(7)` | `pxx` |
| 5 | `m(8)` | `pxy` |
| 6 | `m(4)` | `Qx` |
| 7 | `m(6)` | `Qy` |
| 8 | `m(2)` | 原始四阶矩 `epsilon` |

`ex/ey` 与文献方向完全相同；反向 `[0,3,4,1,2,7,8,5,6]`。
采用 dt=dx=1，`Fx=0`，`Fy=rho0*gBeta*(T-Tref)`，向上为正。
这里的 `F` 已是单步动量增量密度，不能再次乘 rho0 或 dt。
`rho0=1` 固定，不能用局部 rho 替代。精度保持 real(kind=8)。

母版来自带 CDE 选项的程序；本副本 `chi_nu=chi_b=0`，才是此次指定的
Luo/P-TRT 测试。启用 P-TRT 时若改成非零 chi，程序明确中止；并未耦合
CDE 修正或引入独立 MRT 的 s_e / s_epsilon 参数。

## 实际改动

`commondata` 中直接编辑：

- `enablePTRT=.true.`：启用新分支；改为 `.false.` 可在此副本回退原碰撞。
- `ptrtSqStrategy=1`：P1，`Sq=8*(2-Snu)/(8-Snu)`；改为 2 为 P2，`Sq=1.6`。
- `nx/ny`、`Rayleigh`、`unsteadyRunDuration` 等仍是原来的直接参数。

P1/P2 进入同一个 `ptrt_moment_collision`，唯一参数差异为 Sq。三阶平衡态
只增加 `Qx_eq=rho0*u*(3*v²-1)`、`Qy_eq=rho0*v*(3*u²-1)` 的立方项。
最后用 `m_post(2)=-m_post(0)-m_post(1)` 去掉四阶 ghost，而不是独立设置
epsilon 的对角松弛率。使用现有显式 M 与 M^-1，迁移和流体壁面不变。

新分支直接给出 `jx*=jx+Fx`、`jy*=jy+Fy` 以及全部受力后的非守恒矩，
旧 `mSource` 更新只在回退分支执行，不能与新更新叠加。
原代码中已经存在的应变率诊断仍保留，chi=0 时不会施加额外 CDE 应力。

时间推进顺序保留“流场碰撞/迁移/壁面/macro，然后温度碰撞/迁移/壁面/macroT”。
新碰撞前用当前 T^n 的 F^n 与当前 f 重建 `u=(j+F/2)/rho0`。
温度碰撞接收该步流场 macro 的物理速度。macroT 后再用新温度对应的
F^(n+1) 重建下步物理速度；`refresh_ptrt_velocity` 不改变 f，不追加冲量。
初场进入设备后同样按此物理速度约定恢复。

`collisionT/streamingT/bouncebackT/macroT` 与母版逐字一致，温度参数
`paraA,Qk,Qe,Qnu` 的表达式不变。`streaming/bounceback` 同样逐字保留。
检查点二进制字段与 metadata 格式没有改动。此次四组均从零启动。

## 诊断与失败含义

- 原 Nu/Re、耗散、温度剖面历史保留，每 1 t_ff 采样。
- `PTRTCollisionHistory.dat` 每约 0.1 t_ff 在迁移前记录质量、冲量、ghost
  残差，碰撞前 ghost、三阶非平衡最大值、速度/密度/温度极值及温度高阶矩。
- `PTRTWallHistory.dat` 按原 RB 壁面梯度公式补充上下壁 Nu，每 1 t_ff 采样。
- 原奇矩及 f 非平衡监测相应使用新三阶平衡态。原有最大值位置记录保留。
- 非数检测写出检测步与节点/分布方向后非零退出，不把损坏场写成新检查点。
  诊断是离散采样，报告“首次检测时刻”，不声称它一定是实际首发格子步。

## 本地验证

`运行脚本/tools/validate_luo_ptrt.py` 从实际源文件提取 Fortran 子程序编译，
不是只检验 Python 重写的同一公式。独立参照使用分布函数三阶平衡态、
显式 ghost 投影与一/二阶力基。覆盖一般二维力、竖直力、零力和 P1 小 Sq。

验证包括 1200 组局部状态、三阶矩、质量/冲量/ghost、实际 production collision
中的力与速度时层、固定速度下原 D2Q5 的输出一致性，以及 16²/32²
均匀受力周期场、半程反弹 Poiseuille、Taylor–Green 涡。
Poiseuille 比较同一有限时间的启动解析解，区分剩余瞬态与网格误差。
P1/P2 的 Poiseuille 与 Taylor–Green 网格加密均显示约二阶收敛；这不等于
证明新耦合模型在任意非稳态 RB 壁面都零滑移。

实际数值见算例目录 `local_validation.json`。完整源的 P1/P2、两个 Ra
和原碰撞回退分支还分别做语法检查；两种 32²/Ra=1e5/2 t_ff 完整
耦合场主机结果作为 P100 GPU 冒烟对照，比较 u/v/T/rho 的最大绝对差。
GPU 检查结果另存在 `GPU_validation/results/gpu_comparison.json`。
