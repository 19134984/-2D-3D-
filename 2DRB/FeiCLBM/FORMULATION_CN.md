# Fei 2018 原文与本实现

依据正式11页PDF，直接提取全文并视觉核对第3–4页式(7)–(25)、默认cT根号与移动温度波。原文DOI：10.1016/j.ijheatmasstransfer.2017.12.052。本文区分原模型、数值等价求值和项目适配。

## 1. D2Q9流场：双中心矩算法的原文部分

方向0静止，1东、2北、3西、4南、5东北、6西北、7西南、8东南。中心矩按 `00,10,01,20,02,11,21,12,22` 排列，直接求和 `sum f_i*(cx_i-u)^m*(cy_i-v)^n`。式(8)为

```text
kpost = k - S*(k-keq) + (I-S/2)*C
keq = [rho,0,0,rho*cs2,rho*cs2,0,0,0,rho*cs2^2]
C = [0,Fx,Fy,0,0,0,cs2*Fy,cs2*Fx,0]
```

20／02块取对角s+=(sb+snu)/2、非对角s−=(sb−snu)/2；11用snu、21／12用s3、22用s4。s0、s1固定为1，质量严格守恒；本文允许的s0、s1取值不改变守恒关系。体积／剪切率不同，必须使用耦合块，不将两个正应力矩独立取snu。

有力物理速度为 `rho*u=sum(c*f)+F/2`，故碰撞前中心一阶为−F/2，碰后为+F/2，不能在逆平移时把中心一阶量当作零。本实现通过完整二项式把每个中心矩反移到原始矩，再做固定M逆变换。21／12／22均含一阶中心矩的全部交叉项；这是力源与半步速度一致性的必要部分。

例如

```text
m21=k21+v*k20+2*u*k11+2*u*v*k10+u^2*k01+u^2*v*k00
m22=k22+2*v*k21+2*u*k12+v^2*k20+u^2*k02+4*u*v*k11
    +2*u*v^2*k10+2*u^2*v*k01+u^2*v^2*k00
```

原始矩反变换与式(7a)完全等价，未在逐格循环中做矩阵求逆。初始化平衡分布也由连续平衡中心矩的同一逆变换构造，没有退回普通二阶多项式平衡态。

## 2. 外部浮力定义

原文式(3)的F不含局部rho，式(11)的Ri含F/rho、式(14)为rho*u=sum(c*f)+F/2；文中采用不可压参考rho0=1，宏观符号有归一化简写。本实现按rho0=1解释为归一化力密度，取向上热浮力 `Fy=gBeta*(T-Tref)`，不乘瞬时密度。初值、collision、macro及restart四处一致，物理速度除以局部rho的式子保留。

与项目此前常见 `rho*gBeta*(T-Tref)` 不同，这一选择是按论文原文优先；不能把Wei原文含rho的力直接挪进来。初始化f含线性−F/2补偿，使恢复后的物理初速为零；非单位rho的实际生产wrapper测试独立检查该定义。

## 3. D2Q5温度：式(15)–(25)、(34)

默认 **cT²=1/2**，流体cs²=1/3；温度中心矩为 `[T,0,0,T*cT²,T*cT²]`，通量率lambda1=(1/2+kappa/cT²)^−1，高阶lambda2默认1。温度没有物理源、HR时间通量修正或动态滤波。

实际步进先由g直接求中央一、二阶矩，松弛后完整逆移：

```text
T=sum(g)
k10=(1-lambda1)*(m10-u*T)
k01=(1-lambda1)*(m01-v*T)
k20=(1-lambda2)*(m20-2*u*m10+u^2*T)+lambda2*cT²*T
k02=(1-lambda2)*(m02-2*v*m01+v^2*T)+lambda2*cT²*T
m10post=k10+u*T; m20post=k20+2*u*k10+u^2*T
m01post=k01+v*T; m02post=k02+2*v*k01+v^2*T
g0post=T-m20post-m02post
g1post=(m20post+m10post)/2; g3post=(m20post-m10post)/2
g2post=(m02post+m01post)/2; g4post=(m02post-m01post)/2
```

对应原始平衡矩为 `[T,T*u,T*v,T*(cT²+u²),T*(cT²+v²)]`，速度平方项不能省略。cT²=.5时静止权重为0、四个轴向权重.25，非零速度或负温度可产生负g；本模型没有对数熵，不要求分布保正，也不作裁剪。

附录A仍留有混合导数残差 `−kappa/cT² * d_xy(2*T*u*v)`，温度波ux=0不激活此项。因此移动温度波更接近目标扩散率不能证明任意二维速度场完全伽利略不变。

## 4. 几何、边界和统计的项目适配

程序默认四壁封闭方腔。侧热是额外项目算例；RB采用项目温标0.5／−0.5及确定性温度扰动。Fei原文RB是长高比2、温标1.05／0.95、参考T0=1，并在水平中线施加密度余弦扰动。原文RB节没有明确交代侧边界，不能把其他周期算例的文字当作RB周期条件证据；本版也不把自身Nu与该Table1作为同工况逐项比较。

原文默认非平衡速度反弹与温度非平衡外推。本版按用户同一项目框架采用半程无滑移反弹、静壁恒温ABB和绝热镜面；D2Q5仅轴向链接。纯导热测试及低Ra侧热验证检查这些适配后的壁面和Nu，并非原边界逐行复现。

两个碰撞读取同层宏观场，迁移／墙面后先温度后含新浮力半步速度。输出定义保留物理kappa、实际温差与特征长度，时间RMS Re不能直接平均瞬时Re。

## 5. 验证与解释边界

独立公式oracle直接对碰后population求所有中心矩，与式(8)/(19)预期比较；使用非零双向速度／力、非默认高阶率，检查耦合和源项。完整推进／严格续算测试覆盖4宏组合、48步连续对32+16续算，检查相位11步、采样7步，避免对齐时掩盖缺陷。所有g核验使用真实D2Q5维度，不把D2Q9测试改名。

论文的移动温度波有明确周期条件，复现L=100、T0=1、幅值.01、kappa=.05、A=.3/sqrt(3)，推进至phi²*kappa*t约2。报告幅值拟合扩散率、相位误差与解析终点波形误差，不能只用扩散率接近就忽略相位。

低Ra侧热比较Wang/Luo2013的同几何Nu=1.1178，是项目边界实现的交叉检查；不用于证明高RaRB稳定或网格独立。没有LES不等于已获得DNS分辨率，原文高Ra温度快照也不能代替当前程序的空间和时间收敛验证。
