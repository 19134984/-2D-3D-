## 参数沿用

物理参数、网格数和运行/输出控制沿用 `均匀网格/2DRBOpenacc.F90` 与 `ISLBM/2DRBOpenaccISLBM.F90` 的名称。多块布局额外设置 `refineRatio` 和四个 `fineLayerCellsLeft/Right/Bottom/Top` 分区位置；交换层只保留内部常量 `interfaceSkin=2`，粗、细区各延伸两个本地格距。

最细格距 `dxFine=1`，因此细区直接使用原有 `Snu、Sq、Qk、Qnu`，仅粗区保留尺度换算后的松弛率。删除 4 个重复细松弛率、16 个细区积分起止下标、4 个细区积分外框、10 个常驻一维积分权重数组，共 34 个全局量。细区遍历 `1:nxRegion、1:nyRegion`，存储外框由尺寸和坐标偏移就地得到。

全文件检查保留基准已有的 `gBeta1/gBeta`、`velocityUnit`、`velocityScaleCompare`、`thermalGeqCoeff` 及 `unsteadyAverageStartTf/EndTf/MidTf`，沿用原名和公式，半窗口统计使用 `unsteadyAverageMidTf`。续算沿用 `reloadDimensionlessTime`、`reloadItcOffset`、`reloadMetadataLoaded`。多块新增的粗浮力别名和两个重叠层别名已删除，使用处直接写 `dxCoarse*gBeta`、`interfaceSkin*refineRatio` 或 `interfaceSkin`。多块子程序沿用 `Snu、Sq、Qk、Qnu、gBeta`，避免另起缩写。`calNuRe_grid` 直接根据 `nx/ny` 定位物理中线；无需引入单数组节点下标 `nxHalf/nyHalf`。与当前方法无关的 ISLBM 拉伸参数和其他温度算法参数不引入。

粗细格距、松弛率、物理坐标、状态变量、累加器及反复使用的复杂结果仍有独立用途。直接插值中的 `timeWeight0/1/2` 保留 OpenACC `firstprivate` 标量捕获方式，避免 NVHPC 的数组形参捕获问题。

主程序保留基准的 `string`、`numAccDevices`、`unsteadyItcRemaining`：时间字符串、设备数量和非稳态剩余步数使用原名。稳态的误差与步数条件放在 `do while` 入口；非稳态在 `initial` 恢复续算后计算 `unsteadyItcRemaining`，再比较本次 `itc`。稳态/非稳态的 `itc_max` 均在参数定义处取为粗细比的倍数，循环中不再重复换算。所有多块子程序中的整数、实数、字符串声明分别沿用 `integer(kind=4)`、`real(kind=8)`、`character(len=...)`。对应验证记录为 `baseline_style_verification.json`。

参数整理覆盖模块、主程序及计算子程序的声明和使用。单数组中线节点编号 `nxHalf/nyHalf` 不用于多块物理坐标；原时间序列缓存的 `dimensionlessTimeMax/unsteadySampleCount` 也不用于当前逐行写历史的方式，因此不额外补入。当前固定使用旧 D2Q5 算法，不引入其他温度分支的 `taug/useG` 等开关。保留基准参数约定不意味着加入当前流程没有实现的分支或缓存。

## 五套数组的布局

```text
┌──────────┬────────────────────┬──────────┐
│          │        top         │          │
│          ├────────────────────┤          │
│   left   │       coarse       │  right   │
│          ├────────────────────┤          │
│          │       bottom       │          │
└──────────┴────────────────────┴──────────┘
```

这是存储划分示意，未画出粗细重叠。左右细区贯穿全高，上下细区只占中间宽度，所以四个角只有一份细数据。粗网格与外围细区仍有重叠计算区域。

默认物理墙面在 x/y=0、1024，积分分界为 x/y=127.5、895.5。粗计算节点为 123.5～899.5，间距 2。细环有效节点满足：

```text
x≤129.5 或 x≥893.5 或 y≤129.5 或 y≥893.5
```

本次墙面、积分分区线和全部存储范围不变；细网格仍越过分区线延伸两个细格距。

| 区域 | 本地尺寸 | 首节点坐标 | 末节点坐标 |
|---|---:|---|---|
| coarse | 389×389 | (123.5,123.5) | (899.5,899.5) |
| left | 130×1024 | (0.5,0.5) | (129.5,1023.5) |
| right | 131×1024 | (893.5,0.5) | (1023.5,1023.5) |
| bottom | 763×130 | (130.5,0.5) | (892.5,129.5) |
| top | 763×131 | (130.5,893.5) | (892.5,1023.5) |

细数组共 466,407 个节点，粗数组 151,321 个；合计 617,728 个，另有迁移外圈。原细矩形中心的 582,169 个空节点不再分配。

`interfaceSkin` 同时确定粗块外延和细环内延的本地层数，换成细格距分别为 `interfaceSkin*refineRatio` 和 `interfaceSkin`。总重叠跨度为 `interfaceSkin*(refineRatio+1)` 个细格距。接收层按本地节点层数计：默认左侧粗接收层为 123.5、125.5，细接收层为 128.5、129.5。接收层不作为反向交换的数据来源，插值模板可以使用重叠区以外的粗内部节点。两侧延伸与接收层数由同一个常量确定，无需再比较两个相同值；细层厚度、中心宽高和插值模板可用性仍检查。

## 下标与坐标

每套场量的 i/j 从 1 开始，不再使用块编号。例如：

```fortran
T_right(i,j)
x = xOffsetRight+(i-0.5d0)*dxFine
y = yOffsetRight+(j-0.5d0)*dxFine
```

默认 xOffsetRight=893，所以右细区 i=1 对应 x=893.5。粗网格 xOffsetCoarse=122.5、dxCoarse=2，所以粗区 i=1 对应 x=123.5。

各区尺寸直接通过 `size(f_coarse,1/2)`、`size(f_left,1/2)` 等取得，不再另存 `nxCoarse`、`nxLeft` 等尺寸变量。分配时直接写原始分区尺寸及重叠厚度；坐标偏移仍使用 `xOffsetBottom` 等具名量。粗积分下标用 `interfaceSkin` 得到，`centerIntegrationBox` 保存的则是物理坐标。分布函数方向从 0 开始；三份历史数组分别具名，区域下标从 1 开始；迁移临时数组在空间上额外保留 0、n+1 外围位置。

## 正常计算数组

以下名称各有 _coarse、_left、_right、_bottom、_top 五套：

| 名称 | 维度 | 内容 |
|---|---|---|
| f | (ni,nj,0:8) | 流场分布函数 |
| g | (ni,nj,0:4) | 温度分布函数 |
| f_post | (0:ni+1,0:nj+1,0:8) | 碰撞后流场分布及迁移外圈 |
| g_post | (0:ni+1,0:nj+1,0:4) | 碰撞后温度分布及迁移外圈 |
| rho,u,v,T,Fx,Fy | (ni,nj) | 宏观量和单位时间力 |
| up,vp,Tp | (ni,nj)，仅稳态 | 上一次收敛检查保存的场 |

都是普通 allocatable 数组。通用子程序直接接收实际数组，例如：

```fortran
call streaming(size(f_left,1), size(f_left,2), f_left, f_post_left)
```

## initial 的执行顺序

这一过程在主机端准备计算数据；`allocate_grid_arrays` 和 `check_history` 已展开到其中，按下面六段顺序阅读。

1. **检查输入参数。** 先检查粗细比、全域尺寸、加载开关、输出间隔和 paraA。多块模式再检查周期边界限制、interfaceSkin、网格整除、四周细层厚度、中心存储空区以及每方向至少四个粗插值节点。此时尚未分配数组。中心正宽高已被后面的宽度约束包含，删掉重复判断。
2. **设置计数、间隔和几何。** 本次 itc 清零，续算偏移和加载标记置初值。输出间隔按 `ceiling(间隔*timeUnit/refineRatio)*refineRatio` 转换，稳态检查对2000步采用相同取整。随后设置 omega/omegaT、dxCoarse、四条物理分界、各区坐标偏移、墙面标记和粗网格松弛率。原来的数值注释保留。
3. **直接分配数组。** 先分配各区 f，其余场由 `size(f,1/2)` 取得尺寸。默认中心389×389、左130×1024、右131×1024、下763×130、上763×131；f/g 分别有9/5个方向，f_post/g_post 另带0和n+1外围位置。稳态另分配 up/vp/Tp。三个接口历史各为 `(30680,4)`，先清零。
4. **初始化各区并累计面积。** 按中心、左、右、下、上直接写出五段初始化，设置密度、速度、温度、力和完整平衡分布公式；迁移临时数组清零。每段之后直接计算并累计该区物理面积。原 `initial_grid` 和 `owned_cell_area` 均已展开并删除，顺着 `initial` 即可看到所有公式。
5. **检查构建结果并恢复续算。** 检查总积分面积等于 nx*ny。续算时调用 `read_restart` 恢复五区、接口历史、误差和累计计数，并核对文件中的几何、模型与时间设置；随后直接在此读取 Nu/Re 历史，检查有限值、递增时间、采样次数及最后采样时间。此类检查必须在数据产生或读取之后进行。非稳态在这里计算 `unsteadyItcRemaining=max(0,itc_max-reloadItcOffset)`。
6. **建立运行记录。** 写设置日志；全新计算创建 Nu/Re 历史，稳态另创建收敛记录和监测文件。续算保留现有历史供追加。

`itc_max` 的整粗步取整直接写在参数定义处，不增加新的终止步数别名。主循环只比较 `itc < itc_max`（稳态）或 `itc < unsteadyItcRemaining`（非稳态）。以粗细比4、目标39个细步为例，实际终止目标为40；若续算已完成24步，本次剩16步。`MOD(累计步数,间隔)==0` 判断是否到输出/检查时刻，不是反复检查间隔能否被粗细比整除。

## enter_data_2d_openacc 的执行顺序

1. **建立设备存储。** `copyin(ex,ey,omega,omegaT)` 上传方向和权重，接着上传中心场与三份接口历史，多块模式再上传左、右、下、上四区。源数据是刚初始化的数据，或是检查点恢复的数据。up/vp/Tp 用于主机端的稳态检查，不在这里额外上传。
2. **全新多块计算保存 t=0 的粗接口历史。** `save_coarse_history(coarseHistoryCurrent)` 对细接收点直接取粗同位置数据或空间插值，保存转换所需的20个量。Previous/Next 此时仍为零：第一个粗步会先生成 Next，没有过去层时使用线性启动。
3. **补齐粗接收层。** `fine_to_coarse(.false.)` 在同坐标细节点取值，经尺度转换后写入粗外延接收层。
4. **补齐细接收层。** `coarse_to_fine([0,1,0],.false.)` 只选择 Current，并重建细网格接收层。这里没有中间时刻的时间插值，也没有推进时间。

第2～4步只在 `loadInitField==0 .AND. refineRatio>1` 时执行。续算已有匹配的接收层和三个时间层，直接使用上传结果；单网格没有粗细接口。接口操作沿用同一个 async(1) 队列，后续推进按顺序使用这些数据。

原 `grid_device_data` 的建立分支直接放入 enter，释放分支直接放入 exit，取消用真假参数再跳转一层。`initial_grid` 和 `owned_cell_area` 已按逐处展开的方式删除；`read_restart` 等完整文件操作，以及每步调用的推进和插值过程仍保持独立。

## 四个细区怎样迁移

同级细区采用相同格距和时间步，邻点之间直接迁移，不做插值。

1. 子步开始前 `coarse_to_fine(timeInterpWeight,.true.)` 已将接收矩暂存在 f/g 接收层；普通节点仍存分布函数。流场碰撞对接收节点直接读 m，对普通节点由 f 求矩，再统一碰撞，得到各自 f_post。
2. exchange_fine_flow_halos 把相邻细区内部的 f_post 复制到本区迁移外圈，含对角方向所需角部数据。
3. 各区执行原来的 f(i,j,a)=f_post(i-ex(a),j-ey(a),a)。
4. 处理物理墙面，恢复密度和速度。
5. g 中的接收矩保持到此时；温度碰撞直接读接收矩 n，普通节点由 g 求矩，平衡矩均使用更新后的速度。四区碰撞后交换 g_post，再迁移、处理温度边界、恢复 T。

细区拼接线不是墙面，也不是粗细接口，不施加反弹，也不使用 interfaceSkin 插值。

## 粗细交换数组

接口只保存三份小数组：`coarseHistoryPrevious(:,:)`、`coarseHistoryCurrent(:,:)`、`coarseHistoryNext(:,:)`。第二维对应左/右/下/上四区，各区第一维从1开始，区内i先变、j后变，每节点连续20个分量。已删除共用中转数组。各分量含义如下：

| 节点内分量 a | 保存内容 |
|---|---|
| 0:3 | rho、u、v、T |
| 4:5 | Fx、Fy（单位时间力） |
| 6:14 | 流场各矩的 `s/dt*(m-meq+0.5*dt*fm)` |
| 15:19 | 温度各矩的 `q/dt*(n-neq)` |

三个数组分别保存前一、当前、下一粗时刻的数据，供细子步时间插值；默认每份大小为 `(30680,4)`，单网格各为 `(1,1)`。细到粗只在同步时刻读取当前细场，无需细网格历史副本。

`pack_interface_values` 和 `unpack_interface_values` 只处理一个节点，在局部 `buffer(0:19)` 中进行尺度转换，并恢复完整的碰撞前矩。`unpack_interface_values` 的 `keepMoments=.true.` 直接返回 m/n，供碰撞读取；`.false.` 才继续逆变换为完整 f/g。相关子程序显式接收时间步 `dt`；当前采用 `dt=dx`，调用时粗块传 `dxCoarse`，细块传 `dxFine=1`，没有新增重复的全局时间步参数。

推进前只在接收节点的现有 f/g 位置暂存 m/n，不新增整块矩数组。`collision` 和 `collisionT` 的 `grid` 参数为0（单网格）、1（粗区）、2/3/4/5（左/右/下/上细区）；接收范围直接由已有分区参数和 interfaceSkin 判定。两条输入路径共用原来的碰撞公式，因此每个节点只碰撞一次。流场矩逆变换得到 f_post 后才迁移，温度矩必须等待流场速度更新后再碰撞，逆变换得到 g_post 后才迁移。初始化和同步点补齐完整 f/g，检查点不会保存暂存矩。

所有区域按以下约定保存力，并对应 Huang (2014) 的式(5)、(8a)、(19)、(21)：

- `Fx/Fy` 统一保存单位时间的 `F_x/F_y`，不包含时间步。粗、细网格都直接使用相同的 `gBeta` 和磁场系数，不再预乘 `dxCoarse`。
- 接口局部 `fm` 表示式(8a)的单位时间力矩 `F_m`，直接由单位时间力构造，不乘除 `dt`。`buffer(4:5)` 直接保存和恢复 `Fx/Fy`，粗细传递不改变力的单位。
- 碰撞内 `fSource(a)=(1-s(a)/2)*F_m,a` 也是单位时间的源项；在碰撞式中显式写为 `m_post=m-S*(m-meq)+dt*fSource`。它含松弛修正系数，不能直接代入式(19)的 `F_m`。

式(19)在打包端写为 `B_a=(s_a/dt)*(m_a-meq_a+dt*F_m,a/2)`；非守恒矩在接收端按 `m_a=meq_a+(dt/s_a)*B_a-dt*F_m,a/2` 恢复。守恒动量显式恢复为 `m(3)=rho*u-dt*Fx/2`、`m(5)=rho*v-dt*Fy/2`；宏观速度则显式使用 `rho*u=sum(f*ex)+dt*Fx/2`，y方向同理。碰撞和宏观量内核通过 `firstprivate(dt)` 使用本块时间步。

检查点直接保存各区单位时间的力；字段数量和顺序不变，不兼容此前存储 `dt*F` 的旧检查点，也没有添加旧格式转换分支。基准的含密度流场平衡矩和D2Q5温度模型保持原样。

验证见 `unit_force_verification.json`：七组 OpenACC host 短程对照覆盖粗细比1/2/4/8、稳态/非稳态、侧壁差温、磁场及非对称分区。比较时仅在验证脚本内将旧粗力除以粗时间步，其余场量、接口历史、诊断输出及检查点数据与新版本一致；新版本连续与续算一致。另有八组非零力、非平衡状态按独立矩阵公式核对，最大绝对差约 `6.2e-16`。未验证GPU运行和长期收敛。可用 `verify_unit_force.py` 对比本次修改前的源码。

保存时间层时直接读取粗场，共址节点取值，其余节点空间插值，写入本次传入的历史数组。细子步中 `interpolate_coarse_to_fine` 在每个接收节点内完成时间插值、转换和赋值，随后推进细网格，不再清空/装填全局中转数组。

接收范围直接写在调用处：左 `Left+1:Left+interfaceSkin, Bottom+1:ny-Top`，右 `1:interfaceSkin, Bottom+1:ny-Top`，下 `1:size(f_bottom,1), Bottom+1:Bottom+interfaceSkin`，上 `1:size(f_top,1),1:interfaceSkin`。细到粗直接遍历粗数组四条接收带，左右贯穿全高、上下去掉左右已覆盖的角点；用分区编号与粗细比直接换算全域细编号，再选其所在细数组。

所有交换仍在同一 OpenACC `async(1)` 队列内执行。局部buffer、矩和分布函数是线程私有量，时间权重保留标量firstprivate；初始化不再逐节点扫描接口，仅保留保证当前固定布局有效的代数参数检查。

## 一次粗时间步

以 refineRatio=2 为例，从粗细均在 t 时刻开始：

1. `advance_coarse` 先调用 `fine_to_coarse(.true.)`，从同刻细场准备粗接收矩，再直接进入矩空间碰撞并推进到 t+2，空间插值并打包预测接口历史。
2. `coarse_to_fine(timeInterpWeight,.true.)` 用粗历史准备 t 时刻的细接收矩，四套细数组同步推进到 t+1。
3. 同样用粗历史插值得到 t+1 的细接收矩，四套细数组同步推进到 t+2。
4. 同步时 `fine_to_coarse(.false.)` 用细当前数据恢复粗接收层的完整 f/g；粗内部插值来源未变，无需重复生成预测历史。
5. `coarse_to_fine([0,0,1],.false.)` 用下一粗时刻历史补齐细接收层的完整 f/g；前一层←当前层，当前层←下一层，itc=itc+2。

空间上仍用每方向四点 Lagrange；时间上用三时间层，首次粗步线性启动。refineRatio=1 只推进中心数组表示的均匀网格。

## 积分、输出和续算

设 `centerIntegrationBox=[xL,xR,yB,yT]`，物理积分直接由五个互不重叠的矩形相加：

| 物理分区 | x 范围 | y 范围 |
|---|---|---|
| 中心粗区 | xL～xR | yB～yT |
| 左细区 | 0～xL | 0～ny |
| 右细区 | xR～nx | 0～ny |
| 下细区 | xL～xR | 0～yB |
| 上细区 | xL～xR | yT～ny |

物理分区与五套数组的存储边界并不完全相同。各处展开的面积公式直接累加节点控制面积在这些物理矩形内的份额；交换层不另计积分区域，也不采用先积分细存储区再扣中心面积的步骤。每个物理矩形按两个方向的宽度相乘，再累加贡献：以细格面积为 1 计，细网格界面节点面积为 0.5，四个交角为 0.75，纯交换节点为 0，确保总面积为 `nx*ny`。不能简单丢掉所有位于交换存储范围内的节点，其中仍有节点承担分区边缘的物理面积。

左细区初始化的面积公式进一步按本区几何展开为三个矩形：`[0,xL]×[0,ny]`、`[xL,Left+interfaceSkin]×[0,yB]`、`[xL,Left+interfaceSkin]×[yT,ny]`。默认对应左侧主体及其在上下两端的伸出部分；该区到不了右侧物理矩形，因此省去恒为零的右侧项。左区格距为1、坐标偏移为0，节点控制面积直接用 `[i-1,i]×[j-1,j]`，不再重复裁剪存储外框或判断空交集。默认左区总面积为 `127.5*1024+2.5*(127.5+128.5)=131200`，分区线上的半格和角点面积仍逐节点计算。验证记录见 `left_area_simplification_verification.json`。

右细区初始化采用与左侧对称的三个矩形：默认 `[895.5,1024]×[0,1024]`、`[893,895.5]×[0,127.5]`、`[893,895.5]×[895.5,1024]`，总面积132224。下细数组存储 `[130,893]×[0,130]`，只对 `[130,893]×[0,127.5]` 积分，总面积97282.5；上细数组存储 `[130,893]×[893,1024]`，只对 `[130,893]×[895.5,1024]` 积分，总面积98045.5。上下区的节点宽度均为1，只需按行计算有效高度；同一行复用节点面积，保持逐节点累加顺序。代码注释列出默认控制面积、物理范围和半格/零面积节点例子。对照记录见 `right_bottom_top_area_verification.json`。

粗区直接由 `interfaceSkin` 计算积分下标，遍历中心矩形内的节点；细区直接遍历各自完整数组，实际面积在循环中直接计算。`section_owned_weight` 同样累加中线经过的物理线段。

`section_owned_weight`、`fine_value` 通过 `intent(out)` 参数输出积分长度或节点值。面积公式已展开到初始化、Nu/Re、稳态检查、Tecplot及快照输出中，不再调用面积子程序。旧 `fine_skin`、`coarse_interface_node` 已删除，当前粗接收层直接按四条矩形带遍历。

中线 Nu 的四点模板按全局细坐标定位，跨新数组接缝时由 fine_section_x/y 从对应数组取值，不改成单侧模板。

计步沿用基准：`itc` 为本次运行已完成的细步数，启动时清零；`reloadItcOffset` 为续算前的累计细步数，新算例为零、续算从检查点读取。总步数始终为 `reloadItcOffset+itc`。稳态 `itc_max` 限制本次运行步数，非稳态 `itc_max` 是整个算例的总目标；终止时刻向上对齐粗步。直接由 `advance_multiblock` 增加 `itc`，不再另外保存 `step` 或 `itcStart`。

稳态速度/温度误差、非稳态 Nu/Re 窗口统计均保留。输出沿用均匀网格和 ISLBM 的参数：`outputSnapshotIntervalItc`、`reloadFileIntervalItc`、`outputPltFileIntervalItc`，主循环通过 `MOD(reloadItcOffset+itc, 间隔) == 0` 判断。无量纲间隔只在初始化时换算一次，并向上对齐到 `refineRatio` 的整数倍。`NuReSampleCount` 记录累计 Nu/Re 采样次数，实际时间为 `(reloadItcOffset+itc)/timeUnit`；关闭快照不停止采样。写文件前同步所需设备数组。

`coarse_time_weights` 也使用累计步数判断首次启动，续算的 `itc=0` 不会丢弃已经保存的粗网格历史。检查点和快照仍写累计步数；检查点读取时恢复到 `reloadItcOffset` 并清零 `itc`。

`reloadDimensionlessTime` 初始为零，读取完成后由 `reloadItcOffset/timeUnit` 得到，表示续算前的 t_ff；`reloadMetadataLoaded` 初始为假，在二进制检查点完整读取并核对成功后置真。`.meta` 仅提供文件名，不是时间元数据本身；meta 缺失时读取 `reloadFileName` 指定的检查点，成功后同样置真。这些量写入设置日志，输出时刻仍统一使用累计步数除以 `timeUnit`。

主程序按设备与日志、初始化、计时、同步步推进、耗时统计、最终诊断与输出、设备与主机数组释放、结束日志的顺序组织。`CPU_TIME` 记录进程 CPU 时间，`system_clock` 记录实际经过的时间；GPU 工作结束后先等待队列，再停止计时。

稳态检查间隔 `steadyCheckIntervalItc` 将 2000 个细步向上对齐到粗细同步步。例如 `refineRatio=32` 时为 2016，而不是等到 4000 步才偶然满足 `MOD(itc,2000)==0`。`output_steady_monitor` 写入独立的 `SteadyMonitor_2DOpenaccMultiblock.dat`；`output_final_NuRe` 写入 `FinalNuRe_2DOpenaccMultiblock.dat` 并标记是否收敛。它们通过 `calculate_NuRe` 计算当前诊断，不追加正式采样历史，不增加 `NuReSampleCount`。只有按采样间隔调用的 `calNuRe` 更新正式历史和采样次数。

最终 Tecplot、快照和续算文件仍受各自开关控制；本次运行已在终止步输出过的图形或快照不重复写。三类文件均按实际累计 `t_ff` 命名，时间保留十二位小数后去掉末尾的零；最终检查点在必要时更新，`latest.meta` 记录具体文件名。检查点计数直接保存累计步数、已完成采样次数与误差，旧命名计数占位已删除。主程序在 `exit_data_2d_openacc` 释放设备数据后，直接用 `deallocate` 回收五套主机数组及接口存储。

MLUPS 使用本次实际更新节点数。每个同步周期计中心数组的空间节点数，加上 `refineRatio` 乘四个细数组的空间节点数之和；空间节点数由各 `f` 数组第一、二维的 `size` 相乘得到，单网格仅计中心数组。计算包含推进的重叠节点，不包含外围迁移槽位，续算不重复计入此前工作量。接口插值耗时包含在计时内，但不单独计作格点更新。

当前最终诊断包含体平均 Nu、RMS Re、平均速度 Re、冷热壁平均 Nu、中线 Nu 和场量范围；尚未移植旧版的壁面 Nu 极值及位置、中线速度极值、流函数和涡量后处理。

Nu/Re 历史在 `ReVolRMS` 后新增 `ReVolMean`，分别为空间均方根速度和空间平均速度大小乘 `lengthUnit/viscosity`；两者使用同一实际面积权重。独立后处理的快照重算也输出两者；非稳态窗口跳过 `ReVolMean`，仍对 `ReVolRMS` 的平方做时间平均后开方，不增加平均速度 Re 的时间统计。

输出使用固定同步步间隔；检查点直接保存累计步数和已完成的 `NuReSampleCount`，没有三个下一输出序号。读取时核对采样次数、物理签名中的输出间隔及Nu/Re历史。
