# RB 诊断与松弛参数核对（2026-10-20）

本轮仅诊断，不修改主程序、不替换正式算例、不重新统计不完整轨迹。原五组 source 和 NuRe 历史均与提交/前次审计哈希一致。所有诊断计算在独立目录执行，GPU 使用 node07，前台串行。

## 1. Ra=10^6 大误差的主要来源

原始 1000 TFF 最终场呈上下叠放的两个反向主涡。原 500–1000 TFF 的 Nu=4.42324812566、Re=218.389036735，虽然几乎不随时间变化，但不等于文献对应的流动状态。独立快照空间积分与历史末值一致，时间积分也已用 NumPy 独立核对。

保持 Ra、Pr=0.7、Ma=0.1、128 等效细网格、粗细比2和边界条件，只在从零初始化的温度中加入

    deltaT = 1e-3 * sin(2*pi*x/L) * sin(pi*y/H)

五区均使用同一全局坐标函数，随后按新温度构造平衡分布。该扰动在物理墙面为零，不修改墙温。诊断到累计 200.268 TFF，100–200 TFF 后处理得到：

| 量 | 诊断值 | 文献表1 | 相对误差 |
|---|---:|---:|---:|
| Nu | 6.30872037214 | 6.30 | 0.138419% |
| 时空 RMS Re | 280.413654429 | 279 | 0.506686% |

前后半窗口差异：Nu 0.104048%，Re 0.226670%。导出最终场后，主涡变为贯穿方腔的单环流。

这支持初始场/流动分支选择是原大偏差的主要原因，不能仅凭此证明物理多稳态或网格独立性。该短时诊断不替代正式1000 TFF计算。

## 4. 用户提出的“偶矩缩放、奇矩保持魔法参数”

定义平移松弛时间 sigma_nu=1/Snu-1/2、sigma_q=1/Sq-1/2。

细格本来满足

    Lambda_f = sigma_nu,f * sigma_q,f = 3/16.

当前源码对二者都采用除以粗细比r的换算，因此

    sigma_nu,c = sigma_nu,f/r
    sigma_q,c  = sigma_q,f/r
    Lambda_c   = Lambda_f/r^2.

r=2时得到3/64。若按黏性要求缩放偶矩，同时让奇矩重新满足同一Lambda，则应为

    sigma_nu,c = sigma_nu,f/r
    sigma_q,c  = Lambda_f/sigma_nu,c = r*sigma_q,f
    SqCoarse   = 8*(2-SnuCoarse)/(8-SnuCoarse).

这既不同于当前的sigma_q/r，也不同于把Sq数值直接保持不变。若直接保持Sq不变，Lambda只会变为原来的一半，即3/32。

奇矩在这里是不守恒的能量通量相关矩，不直接决定剪切黏性，但会影响稳定性、边界误差和跨网格非平衡矩。不能因为它属于高阶部分就完全忽略其接口匹配。

Ra=10^8：SnuCoarse约1.98527012，当前SqCoarse约0.07612970，保持3/16时约0.01959174。

冻结均匀背景、无浮力扰动的D2Q9线性傅里叶分析，在u=0.03,v=0时，原粗参数最大谱半径约1.002879，保持3/16时约1。Ra=10^9、10^10在同一背景的原粗参数也存在大于1的模态。脚本 spectral_diagnostic.py 可复算。

该分析只是局部线性风险提示，不能代替含接口、非均匀背景、浮力和温度耦合的全局稳定性结论。实际多块试验仍失败，故不能认定恢复魔法参数就是完整修复，也不能把“魔法参数本身不适合粗网格”作为结论。

## 5. 温度的等扩散换算

同一算例各块共享a，但不同Ra/网格算例的a仍由扩散系数计算。对当前D2Q5模型，格子扩散系数满足

    alpha_LB = (4+a)/10 * (1/Qk - 1/2).

粗块dx、dt都为细块的r倍。保持a不变、令(1/Qk,c-1/2)=(1/Qk,f-1/2)/r，则alpha_LB,c=alpha_LB,f/r；换回统一物理单位后扩散系数一致。该代数换算已对五组算例逐项核对。

但扩散相同不保证高阶误差和稳定性相同。Qnu不直接决定上式的主导扩散系数，它的选取不能只由“扩散一致”这一条条件自动证明。当前温度两个平移松弛时间的乘积从细块1/6变为粗块1/24，也说明原固定参数组合的性质需要另行验证。

当前证据中，温度仍有界时流场已发生明显异常，故暂不改温度方案，优先查流场的粗细非平衡矩转换及与空间/时间接口的耦合。若以后考虑各层保持温度Q而让a分层变化，需要同时核对平衡矩、接口pack/unpack、边界及相关标度，不能只替换一处a。
