3. Multi-GPU implementation

    The framework for multi-GPU implementation of thermal
lattice Boltzmann simulations using uniﬁed single-node curved
boundary conditions is shown in Fig. 4. The ﬁrst step for the multi-
GPU computation is domain partitioning and setting the corre-
sponding CPU process and GPU. The next step is to apply for the
host and device memory. Then, the information of lattice nodes
is initialized, and the iterative method [42] is used to obtain dis-
tribution functions consistent with the initial velocity ﬁeld. After
initialization, the data are copied from the host to the device, and
kernels are executed on GPUs. The strategy proposed by Wang and
Aoki [30] is adopted to improve scalability, which can hide the
communicational time using the overlapping mode. The overlap-
ping mode using streams can execute the kernel and copy data be-
tween the host and device simultaneously. The data transfer from
the device to the host is conducted at the end of the kernel, and
then data processing is carried out.
