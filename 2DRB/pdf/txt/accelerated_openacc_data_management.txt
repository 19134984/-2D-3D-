3. OpenACC implementation and optimization

3.1. GPU programming using OpenACC

   CPUs are optimized for low latency access to cached data, while
GPUs are optimized for data parallelism and hide latency with
intensive computations. In OpenACC parallel execution model,
both computation and data are offloaded from the CPU host to
the GPU accelerator, so that the combined tremendous computing
power and superior memory bandwidth of GPU can be utilized.
   To ensure the correctness of the code employing OpenACC
acceleration, an incremental approach to accelerate the code
should be taken. The first step is to assess the numerical algorithm
and estimate the running time each subroutine takes. In LB
method, the standard implementation consists of four subroutines:                                          Fig. 1. Schematic illustration of LB flow chat.
