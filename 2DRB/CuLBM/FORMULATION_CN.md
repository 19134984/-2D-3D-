# CuLBM 一致公式及与原文的差异

本实现依据 Molla（2025），*Development and numerical validations of a two-dimensional cumulant-driven thermal lattice Boltzmann method*，DOI `10.1016/j.rineng.2025.106225`。已渲染并核对 PDF 第5–6页的第4.1、4.2节。以下修正由累积量生成函数及二项式矩变换直接推导；当前没有作者勘误或原始程序来确认作者实际采用的代数。

## 流场：归一化与受力坐标系

记质量 `rho=sum(f)`，raw 均速 `w=sum(e*f)/rho`，加速度 `a=F/rho`。沿用论文式(32)的物理速度：

```text
u = w+a/2
F = (0,rho*gBeta*(T-Tref))
```

二阶以上真正累积量对速度平移不变。实现围绕实际 raw 均速 `w` 计算中心矩并除以 rho，得到 `m20,m02,m11,m21,m12,m22`。此坐标系的一阶中心矩为零，因此式(23)可合法简写为：

```text
c20=m20, c02=m02, c11=m11
c21=m21, c12=m12
c22=m22-m20*m02-2*m11²
```

质量单独守恒，归一化 log-MGF 的零阶为 `ln(1)=0`。二阶平衡为 `cs2,cs2,0`；三阶与混合四阶平衡为零。按论文松弛：

```text
c20* = c20+s2*(cs2-c20)
c02* = c02+s2*(cs2-c02)
c11* = (1-s2)*c11
c21* = (1-s3)*c21, c12*=(1-s3)*c12
c22* = (1-s4)*c22
s2=1/tauf, s3=0.6, s4=1.4
```

逆变换必须恢复累积量扣除的低阶乘积：

```text
m22* = c22*+c20* c02*+2(c11*)²
```

乘回 rho 后得到关于碰撞后 raw 均速的中心矩，再围绕 `w*=u+a/2=w+a` 逆变换到 raw 矩和分布。故单次碰撞保持质量并增加完整动量 `F`。

这一处理与保留物理速度坐标系中的非零一阶累积量完全等价：碰撞前 `c1=-a/2`，按式(26)一阶率1、目标0和归一化源 `a` 得到碰撞后 `c1*=+a/2`。初始化则围绕 `w_initial=u_initial-a/2` 构造平衡累积量，保证物理初速为零。

原文需要澄清的部分：

- 式(25)把零阶归一化平衡写为1，与 log-MGF 定义不同；其率为0，质量不因此改变。
- 式(26)在归一化一阶量上写力密度 F，应统一为加速度 `F/rho`。
- 式(27)强制把碰撞后一阶中心矩置零，会与式(32)半步力定义冲突，丢失部分动量增量。
- 式(28)的简式省略含非零一阶矩时的交叉项，`mu11` 还误写成 `K02`；本程序采用完整二项式变换，避免逐项沿用这些表达。

## 热场：正温度载体的真正累积量

温度 `T=sum(g)`，五个 raw 矩顺序为 `00,10,01,20,02`。以流场物理速度 `(u,v)` 为中心：

```text
K10=r10-u*T, K01=r01-v*T
K20=r20-2*u*r10+u²*T
K02=r02-2*v*r01+v²*T
```

使用 normalized log-MGF 的一、二阶累积量：

```text
c10=K10/T, c01=K01/T
c20=K20/T-c10², c02=K02/T-c01²
```

等价的质量尺度写法为 `C10=K10`、`C20=K20-K10²/T`，另一个方向同理。守恒槽 T 本身不是 log-MGF 的零阶累积量；温度质量与流场密度均另行保存。

原文式(35)、(38)的二阶式缺少 `/T`，只在单位载体等特殊归一化下可省略。直接对任意 T 使用未归一化平方扣除，会得到另一个离散碰撞。本版选择上述真正累积量定义，明确记录此差异。

平衡一阶为零，二阶为 `thermalCs2=1/5`；松弛率按论文取：

```text
sq=1/(0.5+kappa/thermalCs2), s2T=1
c10*=(1-sq)*c10, c01*=(1-sq)*c01
c20*=c20+s2T*(thermalCs2-c20)
c02*=c02+s2T*(thermalCs2-c02)
```

回到中心矩时：

```text
K10*=T*c10*, K01*=T*c01*
K20*=T*(c20*+(c10*)²)
K02*=T*(c02*+(c01*)²)
```

正确的中心矩到 raw 矩逆变换为：

```text
r10*=K10*+u*T, r01*=K01*+v*T
r20*=K20*+2*u*K10*+u²*T
r02*=K02*+2*v*K01*+v²*T
```

式(39)印刷的负号及交叉 u/v 项不满足上述定义，本实现逐项更正。式(40)的五方向 raw 到分布反演保留。静止平衡权重为 `0.6,0.1,0.1,0.1,0.1`，恒温半程 ABB 系数 `2*w_i*Twall=thermalCs2*Twall` 与式(46)一致，绝热链反弹与式(47)一致。

热扩散率按 `kappa=nu/Pr`，与 Pr 的定义及 `tauT=5*kappa+0.5` 一致；原文附近出现的 `Pr/nu` 不予采用。没有使用 CLBM 的 thermalA 或零滑移松弛关系。

## 适用范围与验证解释

默认冷热壁温度为2和1，生产内部温度严格要求 `T>0`。一般 T=0 但热流不为零时，`K10²/T` 没有有限定义；不能靠改写为中心矩或清零分布绕过。设备失败标记一旦置位就保留，检查或输出前明确停止。安全占位不表示恢复了有效解，不要求逐方向 g 为正。

当 `s2T=1` 时，`K20*=T*thermalCs2+(1-sq)²*K10²/T`，故有非零热流的线性导热通常不是逐分布精确不动点。验证应区分：

1. 局部累积量代数、守恒、力与逆变换是否准确。
2. `sq=1` 等明确受控配置下，边界及 Nu 是否保持解析线性导热。
3. 常规 sq 下有限网格的模型截断误差、输运系数和细化趋势。

有限网格下，任意温标平移不会保持这个热模型完全离散等价：平移改变分母 T，而不一定改变热流矩。不得用不成立的逐位平移等价作为验收条件，也不应通过隐藏载体重定义来改变该版本。

本轮只实现论文中与现有基线一致的牛顿流体部分，并按用户要求增加封闭 RB 非稳态算例。非牛顿分支、非均匀网格及论文高 Ra 表格均没有在此宣称完成验证。高阶经验率及正确代数不能单独保证所有算例稳定，仍需要 GPU、低 Mach、壁面、空间分辨率和长期统计核验。
