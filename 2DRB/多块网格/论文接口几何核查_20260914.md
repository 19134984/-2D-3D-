# 三篇多块 LBM 论文的接口几何核查

日期：2026-09-14。仅核对本地原论文 PDF；没有修改求解器。页码同时给出期刊页和 PDF 页，接口图已渲染核查。下文严格区分论文证据与对当前问题的推论。

## 直接结论

这三篇论文讨论了粗细节点耦合、人工接口边缘、缓冲或重叠区，以及相关壁面离散误差。**没有找到任何一篇直接讨论“全域细节点数 nx 为偶数、左右对称取第 N 个细节点为接口、两接口均须属于同一粗格点序列”三条件的奇偶冲突，也没有找到论文要求自动平移右接口的依据。** 不应把自动调整右接口说成文献通用方案。

## Huang & Wu (2014)

Rongzong Huang and Huiying Wu, *Multiblock approach for the passive scalar thermal lattice Boltzmann method*, Physical Review E 89, 043303. [DOI](https://doi.org/10.1103/PhysRevE.89.043303)。本地文件：`pdf/Multiblock approach for the passive scalar thermal lattice Boltzmann method.pdf`。

- 043303-3（PDF 3），图 1 及第 III 节：图中明确分开标注两块间的 interface、fine block boundary 和 coarse block boundary；灰区是两块为信息交换设置的重叠区。粗块边界的数据来自细块，细块边界的数据来自粗块。简短原文："the overlap area ... is set for the convenience of information exchange"。图中的空心粗节点与部分实心细节点重合；不能从示意图再推出本项目的半格距坐标起点。
- 同页式 (12)：比例是空间与时间的共同倍率，`n=δx,c/δx,f=δt,c/δt,f`。
- 043303-4（PDF 4），式 (22) 和图 2：空间采用四点拉格朗日，时间采用三点拉格朗日。空间为三次插值多项式，光滑函数插值误差为四阶；时间层为 `t−δt,c, t, t+δt,c`，求细子步时刻。重叠宽度是否足够必须结合模板，而非只凭“两个粗格距”的文字判断。
- 043303-5（PDF 5），图 4：Couette 验证的分区按几何位置 `0.5L` 标注；采用粗格距 `1/16`、倍率 4。上下物理壁面用非平衡外推边界；不能直接当作当前半格距反弹布局的逐节点依据。
- 043303-7（PDF 7），图 7、表 I：自然对流分块按 `0.5L`、`0.75L` 等几何长度标注，粗细倍率 4，表给各 Ra 的格距。没有定义 `fineLayerCellsLeftRight` 这种“从各墙数第 N 节点”的参数，也没有给出奇偶处理规则。

## Yu, Mei & Shyy (2002)

Dazhi Yu, Renwei Mei and Wei Shyy, *A multi-block lattice Boltzmann method for viscous fluid flows*, International Journal for Numerical Methods in Fluids 39, 99–120. [DOI](https://doi.org/10.1002/fld.280)。本地文件：`pdf/A multi‐block lattice Boltzmann method for viscous fluid flows.pdf`。

- 103、106（PDF 5、8），图 2(a)、第 3 节：MN 为细块边界，AB 为粗块边界；两条人工边界分别位于对方块的内部。沿细块边界，未与粗节点重合的位置用空间插值。原文简短证据："The coarse block boundary is in the interior of the fine block"。
- 106（PDF 8），式 (26)、(27)：空间使用对称三次样条，时间使用三点拉格朗日；作者强调沿接口插值应保持空间对称。这里的“插值对称”不能偷换成对当前任意节点编号布局的证明。
- 102（PDF 4）称 blocks 不重叠而仅通过 interface 耦合；106 的人工边界又位于邻块内部。因此必须按作者的主域/接口术语理解，不能只摘“not overlapped”否定图中的交换层。
- **110（PDF 12），讨论图 16、17 的段落是直接相关的半格距证据**：细块顶壁距最近流体节点为 `0.5 δx,f`。在共用这一物理墙、倍率 m=4 的粗块中，距墙同为 `0.5 δx,f = 0.125 δx,c`，所以细、粗块的无量纲壁面距离分别为 `Δf=0.5` 与 `Δc=0.125`。论文指出由此产生不同边界截断误差，并影响接口靠墙处的应力与压力。作者建议沿整个顶壁附近使用统一尺寸细网格，可改善该问题。
- 上述说明：**粗细节点共址与每个块都使用本块半格距的同一物理墙，不能想当然同时成立。** 但论文没有讨论本项目中心块两端接口的 `nx−2N+1` 整除问题；中心粗块不接触物理墙的布局也不能与该顶壁例子混为一谈。

## Chen et al. (2016)

Songying Chen, Cheng Peng, Yihua Teng, Lian-Ping Wang and Kun Zhang, *Improving lattice Boltzmann simulation of moving particles in a viscous flow using local grid refinement*, Computers & Fluids 136, 228–246. [DOI](https://doi.org/10.1016/j.compfluid.2016.06.009)。本地文件：`pdf/Improving lattice Boltzmann simulation of moving particles in a viscous flow using local grid refinement.pdf`。

- 230–231（PDF 3–4），第 3 节、图 2：主粗域和主细域分开；额外添加 coarse buffer layer `EFGHE`，位于细域内。细域 buffer layer 在粗域边界 `ABCDA` 上；其中与粗边界节点重合的是 fine interface nodes，夹在粗节点之间的是 hanging nodes。
- 231（PDF 4），式 (13)：空间、时间比 `n` 明确仅假定为整数；示意图为 n=2。不能据此声称多块方法的基本概念强制倍率只能是 2 的幂。
- 232–233（PDF 5–6），第 4 节：coarse interface nodes 先从细域转换分布，再迁移给 coarse-domain boundary nodes；fine interface 与 hanging nodes 提供细域迁移所需的数据。共址点转换，悬挂点用三次样条式 (41)，细子步需要时间插值。
- 233（PDF 6）明确主域与 buffer 的区别，简短原文："the buffer layers provide the bridges for information transfer"。碰撞前交换版本的接口节点须参与碰撞；碰撞后交换版本的接口节点不需要再碰撞。
- 233（PDF 6），图 5 的移动规则：移动粒子中心走过一个粗格距时，细域相应移动一个粗格距，维持原有共址结构。这是动态块平移规则，不是为对称接口奇偶冲突而自动挪动单侧界面的方案。
- 238（PDF 11），表 3 将 UCG 和 UCG-L 的特征长度分别列为 129 和 128.5。表格本身未在邻近文字充分解释差异来源，不能仅凭此表推导任意半格距几何修正规则。

## 对当前问题可作的推论（不是论文原文）

若以细格距为单位，墙面在 0 与 nx，两侧都取从墙向内第 N 个节点，则：

`xL=N−0.5`，`xR=nx−N+0.5`，故中心跨度 `D=nx−2N+1`。

若额外要求这两点属于同一等距粗格点序列，则必要且充分的局部一维条件是 `D/r` 为整数。nx 为偶数、r 为偶数时 D 必为奇数，该组合不可能整除。加上整数个粗格距的对称重叠延伸并不改变余数。

此代数冲突来自同时施加的接口定义和格点对齐约束，不是由拉格朗日插值能“修掉”的。可选择调整总节点数、调整一侧接口、改变接口几何定义，或放弃两指定接口均为粗节点而使用相应插值耦合。三篇文献支持“明确主域、人工边界与交换层，然后依真实节点坐标耦合”的方法论；**不直接指定这几种选择中哪一种最适合当前代码**。

若希望左右对称与偶数 nx 同时保留，还可讨论按几何单元面分区、粗细单元中心不共址的设计，但这不是本文核查的三篇共址/缓冲结构可以直接当作现成实现依据的结论；需要另外文献与代码验证。

## 补充：另一种布局分类

主研究线程另外核查了 Schukmann et al. (2023)，[DOI](https://doi.org/10.3390/fluids8030103)，[开放原文 PDF](https://opus.hs-offenburg.de/frontdoor/deliver/index/docId/7066/file/fluids-08-00103-v4.pdf)。正文第 1–2 页图 1 区分 cell-vertex、cell-centered 与 combined 布局：cell-vertex 有部分粗细节点共址；cell-centered 按单元组织，粗细单元中心可以不共址。这为“保持几何单元面分区、允许中心不共址”的设计提供了另一类文献入口。此补充来自主线程的原文核查，本文执行者没有重复独立读取该 PDF。改用单元面接口会改变当前固定第 N 个节点为接口的语义，不能声称它同时满足原来互相冲突的全部条件。
