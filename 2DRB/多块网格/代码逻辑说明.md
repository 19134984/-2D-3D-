# 五套具名数组的存储与计算逻辑

2026-09-20，适用于当前 2DRBOpenaccMultiblock.F90。

## 五套数组的布局

```text
┌──────────┬────────────────────┬──────────┐
│          │        top         │          │
│          ├────────────────────┤          │
│   left   │       coarse       │  right   │
│          ├────────────────────┤          │
│          │       bottom       │          │
└──────────┴────────────────────┴──────────┘
```

这是存储划分示意，未画出粗细重叠。左右细区贯穿全高，上下细区只占中间宽度，所以四个角只有一份细数据。粗网格与外围细区仍有重叠计算区域。

默认物理墙面在 x/y=0、1024，积分分界为 x/y=127.5、895.5。粗计算节点为 123.5～899.5，间距 2。细环有效节点满足：

```text
x≤129.5 或 x≥893.5 或 y≤129.5 或 y≥893.5
```

墙面、积分分区线和粗网格范围不变；细网格越过分区线的延伸从四个细格距缩短到两个细格距。

| 区域 | 本地尺寸 | 首节点坐标 | 末节点坐标 |
|---|---:|---|---|
| coarse | 389×389 | (123.5,123.5) | (899.5,899.5) |
| left | 130×1024 | (0.5,0.5) | (129.5,1023.5) |
| right | 131×1024 | (893.5,0.5) | (1023.5,1023.5) |
| bottom | 763×130 | (130.5,0.5) | (892.5,129.5) |
| top | 763×131 | (130.5,893.5) | (892.5,1023.5) |

细数组共 466,407 个节点，粗数组 151,321 个；合计 617,728 个，另有迁移外圈。原细矩形中心的 582,169 个空节点不再分配。

`coarseOverlapCells=2` 按粗格距控制粗块外延，`fineOverlapCells=2` 按细格距控制细环内延。总重叠跨度为 `coarseOverlapCells*refineRatio+fineOverlapCells` 个细格距。`interfaceSkin=2` 按本地节点层数计：默认左侧粗接收层为 123.5、125.5，细接收层为 128.5、129.5。接收层不作为反向交换的数据来源，插值模板可以使用重叠区以外的粗内部节点。

## 下标与坐标

每套场量的 i/j 从 1 开始，不再使用块编号。例如：

```fortran
T_right(i,j)
x = xOffsetRight+(i-0.5d0)*dxFine
y = yOffsetRight+(j-0.5d0)*dxFine
```

默认 xOffsetRight=893，所以右细区 i=1 对应 x=893.5。粗网格 xOffsetCoarse=122.5、dxCoarse=2，所以粗区 i=1 对应 x=123.5。

几何量直接命名为 nxCoarse、nxLeft、xOffsetBottom 等，没有 xLocalCount(b) 或 meshSpacing(b)。分布函数方向和历史时间层仍从 0 开始；迁移临时数组在空间上额外保留 0、n+1 外围位置。

## 正常计算数组

以下名称各有 _coarse、_left、_right、_bottom、_top 五套：

| 名称 | 维度 | 内容 |
|---|---|---|
| f | (ni,nj,0:8) | 流场分布函数 |
| g | (ni,nj,0:4) | 温度分布函数 |
| f_post | (0:ni+1,0:nj+1,0:8) | 碰撞后流场分布及迁移外圈 |
| g_post | (0:ni+1,0:nj+1,0:4) | 碰撞后温度分布及迁移外圈 |
| rho,u,v,T,Fx,Fy | (ni,nj) | 宏观量和每步力增量 |
| up,vp,Tp | (ni,nj)，仅稳态 | 上一次收敛检查保存的场 |

都是普通 allocatable 数组。通用子程序直接接收实际数组，例如：

```fortran
call streaming(nxLeft, nyLeft, f_left, f_post_left)
```

## 四个细区怎样迁移

同级细区采用相同格距和时间步，邻点之间直接迁移，不做插值。

1. 四区全部完成流场碰撞，得到各自 f_post。
2. exchange_fine_flow_halos 把相邻细区内部的 f_post 复制到本区迁移外圈，含对角方向所需角部数据。
3. 各区执行原来的 f(i,j,a)=f_post(i-ex(a),j-ey(a),a)。
4. 处理物理墙面，恢复密度和速度。
5. 四区全部完成温度碰撞，交换 g_post，迁移、处理温度边界、恢复 T。

细区拼接线不是墙面，也不是粗细接口，不施加反弹，也不使用 interfaceSkin 插值。

## 粗细交换数组

粗网格的时间插值交换量分别保存在 rhoTimeInterp_coarse、uTimeInterp_coarse、vTimeInterp_coarse、TTimeInterp_coarse、FxOverDxTimeInterp_coarse、FyOverDxTimeInterp_coarse、flowNeqTimeInterp_coarse、thermalNeqTimeInterp_coarse 中，最后一维为时间层下标 0:timeInterpMaxIndexCoarse。四个细区采用相同的 TimeInterp、OverDxTimeInterp 命名，后缀分别为 _left、_right、_bottom、_top；细区只保存当前交换时刻的第 0 层，不做三时间层插值。

宏观历史维度为 (ni,nj,0:nh)；两种非平衡矩历史为 (ni,nj,0:8,0:nh)、(ni,nj,0:4,0:nh)。矩编号与分布函数方向编号的含义不同。

粗网格预测下一步后，历史末下标 0/1/2 分别对应过去、当前和预测时刻；细网格只有当前层 0。不同物理量没有再打包成带数字偏移的大数组。

dx 是所在网格的格距，最细格子单位下 dt=dx。因此 FxHistory=Fx/dx 将每步力增量转换到统一时间尺度，接收端再乘自己的 dx。非平衡矩也按格距、松弛率缩放，接收端按自身参数重建 f/g。

连接直接命名为 coarseToLeft/Right/Bottom/Top 及反向 leftToCoarse 等。每条连接有自己的 Ti/Tj 接收节点、Si/Sj 来源模板和空间权重。这些是节点下标，没有块编号。

插值结果写入 rhoReceive、uReceive 等临时数组，再重建接口节点。各方向在同一 OpenACC 异步队列中依次执行，共用接收临时数组。

## 一次粗时间步

以 refineRatio=2 为例，从粗细均在 t 时刻开始：

1. 粗网格先计算到 t+2，保存预测历史。
2. 用粗历史准备 t 时刻的细接口，四套细数组同步推进到 t+1。
3. 用粗历史插值得到 t+1 的接口状态，四套细数组同步推进到 t+2。
4. 使用细当前数据修正粗接口，保存修正后的粗历史。
5. 再由粗网格补细接口，滚动粗历史，itc=itc+2。

空间上仍用每方向四点 Lagrange；时间上用三时间层，首次粗步线性启动。refineRatio=1 只推进中心数组表示的均匀网格。

## 积分、输出和续算

粗积分只覆盖 centerIntegrationBox。四个细存储矩形按节点控制面积积分，再扣除中心区域。xStartIntegration/xEndIntegration/yStartIntegration/yEndIntegration 是数组遍历下标，真实权重由 owned_cell_area 决定，重叠不重复计入物理面积。

owned_cell_area、section_owned_weight、coarse_skin、fine_skin、fine_value 均采用子程序形式，通过最后一个 `intent(out)` 参数输出面积、积分长度、接口判断或节点值。调用处使用 `call`，不再在 commondata 或调用处声明函数返回类型。

中线 Nu 的四点模板按全局细坐标定位，跨新数组接缝时由 fine_section_x/y 从对应数组取值，不改成单侧模板。

稳态速度/温度误差、非稳态 Nu/Re 窗口统计均保留。输出沿用均匀网格和 ISLBM 的参数：`outputSnapshotIntervalItc`、`reloadFileIntervalItc`、`outputPltFileIntervalItc`，主循环通过 `MOD(itc, 间隔) == 0` 判断。无量纲间隔只在初始化时换算一次，并向上对齐到 `refineRatio` 的整数倍。`dimensionlessTime` 记录已完成的 Nu/Re 采样次数，实际时间仍为 `itc/timeUnit`；关闭快照不停止采样。写文件前同步所需设备数组。

主程序按设备与日志、初始化、计时、同步步推进、耗时统计、最终诊断与输出、设备与主机数组释放、结束日志的顺序组织。`CPU_TIME` 记录进程 CPU 时间，`system_clock` 记录实际经过的时间；GPU 工作结束后先等待队列，再停止计时。

稳态检查间隔 `checkIntervalItc` 将 2000 个细步向上对齐到粗细同步步。例如 `refineRatio=32` 时为 2016，而不是等到 4000 步才偶然满足 `MOD(itc,2000)==0`。`output_steady_monitor` 写入独立的 `SteadyMonitor_2DOpenaccMultiblock.dat`；`output_final_NuRe` 写入 `FinalNuRe_2DOpenaccMultiblock.dat` 并标记是否收敛。它们通过 `calculate_NuRe` 计算当前诊断，不追加正式采样历史，不增加 `dimensionlessTime`。只有按采样间隔调用的 `calNuRe` 更新正式历史和采样次数。

最终 Tecplot、快照和续算文件仍受各自开关控制；本次运行已在终止步输出过的图形或快照不重复写。最终检查点在必要时更新，保存最终文件编号。`deallocate_grid_arrays` 在设备数据释放后回收五套主机数组及接口存储。

MLUPS 使用本次实际更新节点数。每个同步周期计 `nxCoarse*nyCoarse + refineRatio*(nxLeft*nyLeft + nxRight*nyRight + nxBottom*nyBottom + nxTop*nyTop)` 次节点更新；单网格仅计中心数组。计算包含推进的重叠节点，不包含外围迁移槽位，续算不重复计入此前工作量。接口插值耗时包含在计时内，但不单独计作格点更新。

当前最终诊断包含体平均 Nu、RMS Re、冷热壁平均 Nu、中线 Nu 和场量范围；尚未移植旧版的壁面 Nu 极值及位置、中线速度极值、流函数和涡量后处理。

原来逐个目标时刻向上取整的输出方式已改为固定格子步间隔，因此不能保证旧计算的输出时刻与新方式相同。续算文件仍保留三个输出序号的位置，但序号由累计步数和采样次数计算；读取时检查计数与历史时间，不匹配的旧输出计划会被拒绝。

续算文件直接从网格参数开始，保存五套数组的几何、f/g、宏观量、力、时间历史和稳态检查场，以及全局输出计数和配置。原有的 16 字节文本格式标识已删除，带标识的旧文件不能直接读取。旧对称布局文件不能直接用于当前缩小后的细数组；要继续旧布局计算，设置 `fineOverlapCells=coarseOverlapCells*refineRatio`，使文件记录的尺寸和坐标与当前一致。旧 v10 可通过 convert_restart_v10.py 转换为当前无文本标识的格式；转换保留旧布局，需恢复旧宽度、保留匹配的历史文件并更新 latest.meta。

快照直接从区域数量开始，随后保存几何、一维权重、二维积分面积和 u/v/T/rho；多网格时区域数量为五个，不再写入文本格式标识。

建议阅读顺序：initial → allocate_grid_arrays → advance_multiblock → advance_coarse/advance_fine → coarse_to_fine/fine_to_coarse → calNuRe。
