# 五套具名数组的存储与计算逻辑

2026-09-18，适用于当前 2DRBOpenaccMultiblock.F90。

## 五套数组的布局

```text
┌──────────┬────────────────────┬──────────┐
│          │        top         │          │
│          ├────────────────────┤          │
│   left   │       coarse       │  right   │
│          ├────────────────────┤          │
│          │       bottom       │          │
└──────────┴────────────────────┴──────────┘
```

这是存储划分示意，未画出粗细重叠。左右细区贯穿全高，上下细区只占中间宽度，所以四个角只有一份细数据。粗网格与外围细区仍有重叠计算区域。

默认物理墙面在 x/y=0、1024，积分分界为 x/y=127.5、895.5。粗计算节点为 123.5～899.5，间距 2。细环有效节点仍满足：

```text
x≤131.5 或 x≥891.5 或 y≤131.5 或 y≥891.5
```

改变的是存放位置，没有移动墙面、粗细分界或粗细节点。

| 区域 | 本地尺寸 | 首节点坐标 | 末节点坐标 |
|---|---:|---|---|
| coarse | 389×389 | (123.5,123.5) | (899.5,899.5) |
| left | 132×1024 | (0.5,0.5) | (131.5,1023.5) |
| right | 133×1024 | (891.5,0.5) | (1023.5,1023.5) |
| bottom | 759×132 | (132.5,0.5) | (890.5,131.5) |
| top | 759×133 | (132.5,891.5) | (890.5,1023.5) |

细数组共 472,495 个节点，粗数组 151,321 个；合计 623,816 个，另有迁移外圈。原细矩形中心的 576,081 个空节点不再分配。

## 下标与坐标

每套场量的 i/j 从 1 开始，不再使用块编号。例如：

```fortran
T_right(i,j)
x = xOffsetRight+(i-0.5d0)*dxFine
y = yOffsetRight+(j-0.5d0)*dxFine
```

默认 xOffsetRight=891，所以右细区 i=1 对应 x=891.5。粗网格 xOffsetCoarse=122.5、dxCoarse=2，所以粗区 i=1 对应 x=123.5。

几何量直接命名为 nxCoarse、nxLeft、xOffsetBottom 等，没有 xLocalCount(b) 或 meshSpacing(b)。分布函数方向和历史时间层仍从 0 开始；迁移临时数组在空间上额外保留 0、n+1 外围位置。

## 正常计算数组

以下名称各有 _coarse、_left、_right、_bottom、_top 五套：

| 名称 | 维度 | 内容 |
|---|---|---|
| f | (ni,nj,0:8) | 流场分布函数 |
| g | (ni,nj,0:4) | 温度分布函数 |
| f_post | (0:ni+1,0:nj+1,0:8) | 碰撞后流场分布及迁移外圈 |
| g_post | (0:ni+1,0:nj+1,0:4) | 碰撞后温度分布及迁移外圈 |
| rho,u,v,T,Fx,Fy | (ni,nj) | 宏观量和每步力增量 |
| up,vp,Tp | (ni,nj)，仅稳态 | 上一次收敛检查保存的场 |

都是普通 allocatable 数组。通用子程序直接接收实际数组，例如：

```fortran
call streaming(nxLeft, nyLeft, f_left, f_post_left)
```

## 四个细区怎样迁移

同级细区采用相同格距和时间步，邻点之间直接迁移，不做插值。

1. 四区全部完成流场碰撞，得到各自 f_post。
2. exchange_fine_flow_halos 把相邻细区内部的 f_post 复制到本区迁移外圈，含对角方向所需角部数据。
3. 各区执行原来的 f(i,j,a)=f_post(i-ex(a),j-ey(a),a)。
4. 处理物理墙面，恢复密度和速度。
5. 四区全部完成温度碰撞，交换 g_post，迁移、处理温度边界、恢复 T。

细区拼接线不是墙面，也不是粗细接口，不施加反弹，也不使用 interfaceSkin 插值。

## 粗细交换数组

每套网格分别保存 rhoHistory、uHistory、vHistory、THistory、FxHistory、FyHistory，以及 flowNeqHistory、thermalNeqHistory。

宏观历史维度为 (ni,nj,0:nh)；两种非平衡矩历史为 (ni,nj,0:8,0:nh)、(ni,nj,0:4,0:nh)。矩编号与分布函数方向编号的含义不同。

粗网格预测下一步后，历史末下标 0/1/2 分别对应过去、当前和预测时刻；细网格只有当前层 0。不同物理量没有再打包成带数字偏移的大数组。

dx 是所在网格的格距，最细格子单位下 dt=dx。因此 FxHistory=Fx/dx 将每步力增量转换到统一时间尺度，接收端再乘自己的 dx。非平衡矩也按格距、松弛率缩放，接收端按自身参数重建 f/g。

连接直接命名为 coarseToLeft/Right/Bottom/Top 及反向 leftToCoarse 等。每条连接有自己的 Ti/Tj 接收节点、Si/Sj 来源模板和空间权重。这些是节点下标，没有块编号。

插值结果写入 rhoReceive、uReceive 等临时数组，再重建接口节点。各方向在同一 OpenACC 异步队列中依次执行，共用接收临时数组。

## 一次粗时间步

以 refineRatio=2 为例，从粗细均在 t 时刻开始：

1. 粗网格先计算到 t+2，保存预测历史。
2. 用粗历史准备 t 时刻的细接口，四套细数组同步推进到 t+1。
3. 用粗历史插值得到 t+1 的接口状态，四套细数组同步推进到 t+2。
4. 使用细当前数据修正粗接口，保存修正后的粗历史。
5. 再由粗网格补细接口，滚动粗历史，itc=itc+2。

空间上仍用每方向四点 Lagrange；时间上用三时间层，首次粗步线性启动。refineRatio=1 只推进中心数组表示的均匀网格。

## 积分、输出和续算

粗积分只覆盖 centerBox。四个细存储矩形按节点控制面积积分，再扣除中心区域。iFirst/iLast/jFirst/jLast 是遍历范围，真实权重由 owned_cell_area 决定，重叠不重复计入物理面积。

中线 Nu 的四点模板按全局细坐标定位，跨新数组接缝时由 fine_section_x/y 从对应数组取值，不改成单侧模板。

稳态速度/温度误差、非稳态 Nu/Re 窗口统计、独立采样与输出时钟均保留。写文件前同步所需设备数组。

v11 续算文件保存五套数组的几何、f/g、宏观量、力、时间历史和稳态检查场，以及全局输出计数和配置。旧 v10 可通过 convert_restart_v10.py 转换；保留匹配的历史文件并更新 latest.meta。

v3 快照继续保存区域数量、几何、一维权重、二维积分面积和 u/v/T/rho；多网格时区域数量现为五个。

建议阅读顺序：initial → allocate_grid_arrays → advance_multiblock → advance_coarse/advance_fine → coarse_to_fine/fine_to_coarse → calNuRe。
