# 连通细网格环：代码逻辑说明

2026-09-15。当前 `2DRBOpenaccMultiblock.F90` 使用两个计算区域：中心粗矩形（编号 1）和外围连通细环（编号 2）。原均匀网格文件未修改。

## 为什么现在没有细块之间的交换

以前上、下、左、右各存一套 `f,g`，同坐标还可能有多份副本。现在所有细节点统一放在编号 2 的二维数组中。原来的四个角部拼接位置只是普通相邻节点，迁移直接执行：

```text
f(i,j,alpha) = f_post(i-ex(alpha), j-ey(alpha), alpha)
```

因此 `nBlocks=2`，`build_links` 只建立粗→细、细→粗两条连接。没有细→细连接，也没有原细块接缝的缓冲层。

![当前两区域布局](图示/multiblock-layout.png)

## 存储和活动区域

细环采用 `nx × ny` 二维存储，保留规则索引。中心空区占据数组位置，但 `fine_active` 将它排除在流场/温度碰撞、迁移和宏观量更新之外。空区不是固体，不施加反弹边界。粗网格负责中心的物理计算。

默认参数：

| 参数 | 值 | 对应坐标 |
|---|---:|---|
| `fineLayerCellsLeft` | 128 | `xLeft=127.5` |
| `fineLayerCellsRight` | 129 | `xRight=895.5` |
| `fineLayerCellsBottom` | 128 | `yBottom=127.5` |
| `fineLayerCellsTop` | 129 | `yTop=895.5` |
| `refineRatio` | 2 | 粗格距/时间步为 2，细格距/时间步为 1 |
| `overlapCells` | 2 | 每侧延伸 4 个细格距 |
| `interfaceSkin` | 2 | 仅粗细接口的两层接收节点 |

中心粗节点范围为 `[123.5,899.5]²`。细网格活动条件是：

```text
x <= 131.5 或 x >= 891.5 或 y <= 131.5 或 y >= 891.5
```

其余细节点处于中心非活动空区。这个逻辑“或”保证四周及四角属于同一个连通细网格。

默认分配细数组节点 1,048,576 个，其中活动节点 472,495 个；中心粗节点 151,321 个。两级合计分配 1,199,897 个节点位置，实际活动 623,816 个。**这版优先保持二维寻址简单，没有实现只存环上节点的紧凑存储，显存占用高于原五矩形实现。**

## 粗细接口仍如何交换

以左侧为例：基准边界和积分分界同在 `x=127.5`。粗节点首列 `123.5`，细环向中心延伸至 `131.5`，重叠跨度 8，含端点 9 排细点、5 排粗点。

- 粗网格接收列为 `123.5、125.5`，从细环内部同坐标节点读取交换量。
- 细环接收列为 `130.5、131.5`，从粗网格内部取值；角部由环形缓冲判据与来源模板检查处理。
- 细环的中心空区、以及两级待修复缓冲，均不能作为来源点。

![粗细共址节点](图示/multiblock-interface.png)

Huang 四点 Lagrange 保留：完全重合直接读取；一个方向不重合取四点；两个方向都不重合取 4×4 张量积。例如 `(130.5,511.5)` 使用同一粗行的 `127.5、129.5、131.5、133.5`，权重 `(-1,9,9,-1)/16`。来源点可以在重叠带之外，但必须属于来源块有效内部。

交换仍先打包 `rho,u,v,T`、力和归一化非平衡矩，再按目标松弛率重建分布。流场非守恒矩采用：

```text
K = s/h * (m - meq + Fmoment/2)
m_target = meq_target + h_target/s_target*K - Fmoment_target/2
```

温度场继续沿用原 D2Q5 和 `B_prev` 源项历史适配，没有换成论文的另一套温度模型。

## 一次粗步

细步为 1，粗步为 2，两级从同一个时刻 t 开始：

1. 粗网格使用准备好的缓冲，从 t 预测到 t+2，保存粗时间层。
2. 给细环内边缘准备 t 时刻数据；整个连通细环碰撞、迁移到 t+1。
3. 给细环内边缘准备 t+1 数据；整个细环推进到 t+2。
4. 在 t+2 先细→粗修复粗缓冲，再补齐细缓冲，滚动历史，最后输出或保存检查点。

中间时刻采用三时间层插值 `Q(t+1)=-Q(t-2)/8+3Q(t)/4+3Q(t+2)/8`。首个粗步缺少负时间层，使用 t 与 t+2 的平均值启动。

收到的是碰撞前状态，接收节点参加随后碰撞。这保留了选择的 Huang 插值与 Chen 碰撞前交换原则。

![一次粗步的时序](图示/multiblock-timestep.png)

每个区域内部顺序不变：流场碰撞→迁移→真实壁面→宏观速度/力→温度碰撞→温度迁移→温度壁面→温度。两层粗细缓冲仍用于隔离这段流热分步推进的边缘依赖。

## 面积和中线统计为什么也要改

细环不再是四个独立矩形，所以不能把整个细数组乘 `dxWeight*dyWeight` 求和。

`owned_cell_area` 对细节点的控制面积减去与中心物理矩形 `[127.5,895.5]²` 的交集；粗网格只积分这个中心矩形。这样空区权重为零，接口处用部分面积，两级总面积恰为 `nx*ny`。

`section_owned_weight` 对中线作同样的长度扣除。温度/密度极值跳过零面积节点，避免中心非活动数据影响统计。物理壁面现在全部属于细环，仍用原 BB/ABB 和壁面 Nu 公式。

## 文件格式

- 检查点改为 `MB2DRESTART0009`。旧五块检查点不能恢复到新的两区域存储，需重新初始化。
- 场快照改为 `MB2DSNAPSHOT0003`。每区仍写尺寸、首节点坐标、格距、外框和两个一维权重，随后新增 **二维实际面积数组**，再写 `u,v,T,rho`，均按 Fortran 顺序。
- 快照中细环外框覆盖全域；读取器必须使用新增的二维面积，不能用两个一维权重相乘代替。空区及纯缓冲处为零面积。
- Tecplot 保留规则矩形区输出，`integration_area/L^2=0` 的位置必须在显示/积分时屏蔽；否则会把中心非活动占位数据画出来。

## 代码阅读顺序与验证

从 `advance_multiblock` 看时间顺序，再读 `fine_active`（活动区）、`skin_node`（粗细缓冲）、`donor_stencil/build_links`（仅两级连接）、`streaming`（原拼接处直接寻址），最后读 `owned_cell_area/section_owned_weight`（避免积分重复）。

`verify_ring.py` 检查两条连接、面积、原拼接处流场/温度直接迁移、空区不迁移、导热、单块回归及精确续算；`verify_multiblock.py` 在本版自动转入这些检查。`transient_compare.py` 支持 v3 快照并进行低 Ra 瞬态对照。结果保存在 `ring_verification_results.json` 与 `ring_transient_comparison.json`，以源码哈希识别版本。

本机 OpenACC host 检查不能替代 NVIDIA GPU 编译运行、高 Ra 长期稳定性或收敛阶研究。旧五块的验证 JSON 保留作历史记录，不代表本版。
