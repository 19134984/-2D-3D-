# 2DRBOpenaccMultiblock

`2DRBOpenaccMultiblock.F90` 从 `../均匀网格/2DRBOpenacc.F90` 复制派生，原文件未修改。

参考文献：Huang, R. and Wu, H., *Multiblock approach for the passive scalar thermal lattice Boltzmann method*, Physical Review E **89**, 043303 (2014), DOI: [10.1103/PhysRevE.89.043303](https://doi.org/10.1103/PhysRevE.89.043303)。本地全文为 `../pdf/Multiblock approach for the passive scalar thermal lattice Boltzmann method.pdf`，主要依据第 III 节式 (19)-(22)。

先读 [代码逻辑说明](代码逻辑说明.md)：从一次粗步解释缓冲节点、取点与时间交换；时序图见 `图示/multiblock-timestep.png`。

当前方案：Huang 的含力 MRT 转换和四点 Lagrange，结合 Chen 的碰撞前缓冲节点处理；保留 Yu 的粗细同步组织思想，不采用三次样条或碰撞后转换。

## 源码阅读顺序

源码依次为 `module commondata → program main → 外部子程序`。主程序紧接全局参数和数组声明；子程序通过 `use commondata` 引用需要的变量，不使用 `contains`、`gridBlock` 或 `blockLink` 派生类型。

块的几何量使用 `blockNi(b)`、`blockH(b)`、`blockBaseBox(:,b)` 等普通数组。场量按各块实际大小依次放入连续存储，不把小块补成最大矩形。`select_block(b)` 用指针将 `u(i,j)`、`f(i,j,k)` 等数组指向第 `b` 块，既不分配也不复制数据；调用块内计算前先选择对应块。设备内核仍通过显式尺寸的数组形参访问数据。`select_link(l)` 同样选择第 `l` 条接口连接的索引、权重和交换缓存。

这次调整保持几何、插值、积分和二进制输出顺序，重启格式仍为 `MB2DRESTART0007`。修改前后对照记录见 `layout_refactor_verification.json`；该记录是本地 OpenACC host 检查，不代表 GPU 验证。

## 稳态与非稳态功能范围

两种模式的核心流程均保留：`steadyFlow` 按 `epsU/epsT` 检查收敛，`unsteadyFlow` 按目标时间推进并计算指定窗口及前后半窗口的 Nu/Re 统计。两种模式均支持完整续算和独立的文件输出开关。稳态误差和 Nu/Re 空间统计按多块积分分区加权，不能直接按节点数平均。

尚未完全对齐均匀网格版本的结束后处理：壁面 Nu 极值及位置、中心线速度极值及位置、流函数/涡量等诊断未移植；稳态停止时也尚未保证追加最后一步的 Nu/Re 和快照。这次源码结构调整保留当前行为，没有把这些缺项当作已经完成。五块布局还不支持侧边周期拓扑。

## 保留的原算法

- D2Q9 流场 MRT：原矩基、平衡矩、Guo 浮力源、宏观速度半步力修正。
- D2Q5 温度 MRT：默认 `EnableUseG`，保留 `T*u/T*v` 的历史差分修正；也保留原 `EnableLegacyThermalScheme` 分支。
- 每块执行原顺序：`collision → streaming → bounceback → macro → collisionT → streamingT → bouncebackT → macroT`。
- 保留原流体节点距物理壁面半个格距的布置以及物理壁面的 BB/ABB。
- 默认仍为原程序的封闭 Rayleigh-Bénard 算例：`Ra=1e7, Pr=0.7, Ma=0.1`，上下恒温，侧壁绝热，四壁无滑移，初始温度扰动与原程序相同。

论文使用 D2Q9 温度模型。本文件把其一般 MRT 接口关系应用于原 D2Q5 矩基，未把块内温度模型换成论文的 D2Q9。文献的局部热流后处理公式也没有直接套入本文件。

## 网格参数

参数集中在文件开头的 `module commondata`。

瑞利数也直接在源码中设置：`Rayleigh=1.0d7` 表示 `Ra=10^7`，修改后重新编译；本多块文件不再使用 `RAYLEIGH_OVERRIDE`。验证脚本仅在临时源码中替换瑞利数。

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `nx,ny` | 1024,1024 | 最细格距下的等效全域分辨率，直接修改 Fortran 参数 |
| `refineRatio` | 2 | 粗细格距及时间步之比；整数 2、3、4、…，设 1 时退化为原单块均匀网格 |
| `fineLayerCellsLeftRight,fineLayerCellsBottomTop` | 128,128 | 从各物理墙壁向内数的接口细节点编号；128 对应距墙 127.5 个细格距 |
| `overlapCells` | 2 | 各块从自身基准边界向外延伸的粗格距数；粗块先补齐右/上基准边界，再延伸；总重叠宽度还包含基准边界差 |
| `interfaceSkin` | 2 | 在下一次碰撞前由相邻块重建的人工边界节点层数，以各块自身格距计 |
| `loadInitField` | 0 | 设 1 优先按 `latest.meta` 精确续算；缺失时使用手动编号 |
| `reloadFileNum` | 0 | `latest.meta` 缺失时手动填写已有检查点编号；正常运行时记录实际输出编号 |
| `unsteadyRunDuration` | 1000 | 非稳态绝对目标时间，单位 `t_ff` |

默认五块的**物理积分分区**如下；分区面积互不重叠。各块计算节点可以重合，统计按裁剪后的控制面积加权，避免面积重复计入。

```text
  +-----------------------------------+
  |             3: 上细块             |
  +--------+-----------------+--------+
  |        |                 |        |
  |4: 左细 |    1: 中心粗    |5: 右细 |
  |        |                 |        |
  +--------+-----------------+--------+
  |             2: 下细块             |
  +-----------------------------------+
```

每个块内部是等距正方形格子，全域通过不同格距的块实现局部加密。默认中心 `h=2`、四周 `h=1`；最细格距为长度单位 1。

多块模式下，仅 `nx,ny` 必须为 `refineRatio` 的整数倍；两个接口节点编号取正整数，无须被粗细比整除。左/右接口坐标分别是 `fineLayerCellsLeftRight-0.5`、`nx-fineLayerCellsLeftRight+0.5`；下/上同理。距墙厚度（编号减 0.5）至少为 `(overlapCells+1)*refineRatio` 个细格距；中心须满足 `nx-2*fineLayerCellsLeftRight+1 > 0`、`ny-2*fineLayerCellsBottomTop+1 > 0`。`interfaceSkin` 保持 2；来源范围要求 `2*overlapCells*refineRatio >= interfaceSkin*refineRatio+interfaceSkin-1`，随后程序逐节点检查来源模板。

例如，手动设置 `1024×1024`、粗细比 4、接口取各墙向内第 128 个细节点：

```fortran
integer, parameter :: nx=1024, ny=1024
integer, parameter :: refineRatio=4
integer, parameter :: fineLayerCellsLeftRight=128, fineLayerCellsBottomTop=128
```

修改后重新编译；本多块文件不再使用 `NX_OVERRIDE/NY_OVERRIDE`。改小 `nx,ny` 时也要相应修改接口节点编号，它们不再自动取 `nx/8,ny/8`。例如 `96×96`、比值 2、编号各 12 对应每侧厚度 11.5 个细格距。粗细比越大，中心越粗，每个粗步对应的细步越多；可配置不等于已验证高比值下的精度或稳定性。改变网格后必须重新初始化，不能读取旧网格检查点。

### 当前默认：对齐节点与两层碰撞前缓冲

中心最小尺寸由实际节点覆盖、非负积分权重和每个接收点的来源模板决定，不再写死为 8 个粗格距，也不直接改成固定的 2。四点拉格朗日使用三次多项式，通常具有四阶插值精度；四个来源节点跨越三个来源格距。默认 `overlapCells=2,interfaceSkin=2` 时，中心每方向宽两个粗格距会生成 7 个粗节点，排除两端各两层后只剩 3 个可用粗节点，不能从该粗块构造四点模板；但周围细块的重叠区可提供同级来源，所以该布局仍可能有效。程序按实际来源建连接，不能把这样的成功运行当作“两粗节点即可作四点插值”的证据。

细格点保持原程序的半格距位置，粗格点成为细格点的子集：

\[
x_f=0.5+k,\qquad x_c=x_b+\texttt{refineRatio}\,k,\quad k\in\mathbb Z,
\]

`y` 同理。`xb` 已是半整数的首节点坐标，不再额外加 0.5；默认中心粗块 `xb=123.5`。代码内部仍用 `x=x0+(i-0.5)*h`，但 `x0=xb-h/2`；因此粗块的 `x0` 是虚拟控制区的左侧面，不能当作物理积分分区边界。真实壁面附近仅使用细块，第一、最后节点仍为 `0.5`、`N-0.5`，原 BB/ABB 不变。

以左细块与中心粗块为例：第 128 个细节点是 `x=127.5`，该坐标同时作为两块的基准边界和物理积分分界。粗块从 `123.5` 开始，细块延伸至 `131.5`，重叠节点范围跨度为 `8=2×overlapCells×refineRatio`。粗细共同节点为 `123.5,125.5,…,131.5`。`interfaceSkin=2` 对应粗块首两列 `123.5,125.5`、细块末两列 `130.5,131.5`。

右侧细块基准边界仍为从右墙向内第 128 个节点 `896.5`。中心粗块先从左基准 `127.5` 按格距 2 向右排列，将右基准向外补齐至 `897.5`；再从自己的基准边界延伸 4，得到粗块末节点 `901.5`。右细块仍从 `896.5` 向左延伸 4，首节点为 `892.5`。物理积分分界取共址节点 `897.5`：中心积分到这里，右细块从这里开始积分。因此右侧计算重叠为 `[892.5,901.5]`，跨度 9；左侧跨度为 8，不能把所有接口的重叠宽度都固定写成 8。下侧与左侧同理，上侧与右侧同理。这里的基准边界及计算边界均按人工边缘节点坐标描述，不是固体壁面。

一般情况下，中心粗块右基准为 `xLeft+ceiling((xRight-xLeft)/refineRatio)*refineRatio`，上基准同理；补齐量在 `[0,refineRatio)` 内，已整除时不额外增加节点。`blockBaseBox` 记录添加重叠层前的基准边界；中心 `blockOwnedBox` 等于中心 `blockBaseBox`，相邻细块的统计范围统一接到这些共址节点。设置文件同时输出这两种边界及实际首末节点坐标。

默认五块统计区域依次为：中心 `[127.5,897.5]×[127.5,897.5]`；下 `[0,1024]×[0,127.5]`；上 `[0,1024]×[897.5,1024]`；左 `[0,127.5]×[127.5,897.5]`；右 `[897.5,1024]×[127.5,897.5]`。角部也采用同一分界线，各矩形内部互不重叠，总面积仍为 `1024²`。这些统计分区不改变细块原有计算节点。

| 块 | `h` | 计算节点 x 范围 | 计算节点 y 范围 | 实际推进节点数 | 正面积积分节点数 |
|---|---:|---|---|---|---|
| 中心粗块 | 2 | 123.5–901.5 | 123.5–901.5 | 390×390 | 386×386 |
| 下细块 | 1 | 0.5–1023.5 | 0.5–131.5 | 1024×132 | 1024×128 |
| 上细块 | 1 | 0.5–1023.5 | 892.5–1023.5 | 1024×132 | 1024×127 |
| 左细块 | 1 | 0.5–131.5 | 123.5–900.5 | 132×778 | 128×771 |

计算节点共 627828 个，正面积积分样本共 606721 个；后者不是去重后的坐标数。上下及左右细块的计算节点数保持对称，统计分区因选择粗块共址边界而不再完全对称。中心粗序列从左下首节点开始排列，右上多出的计算覆盖由重叠区容纳。接口历史数组和插值增加了开销，不能仅凭节点数推断 GPU 加速比。

`图示/multiblock-layout.png`、`图示/multiblock-interface.png` 及原绘图脚本记录的是改为节点编号之前的历史布局，不能用其中的 `128/128.5` 接口位置解释当前代码；当前坐标以上表和程序输出的 `blockOwnedBox` 为准。时间推进图的算法顺序不受本次坐标定义变更影响。

当前是静态两级布局。多块模式支持原封闭 RB 和侧壁差温两类物理边界；周期侧边需要专门的周期块连接，目前多块模式会明确拒绝此配置。`refineRatio=1` 保留原周期宏路径。

## 粗细块的物理单位与松弛率

设块 (b) 的格距、时间步为

\[
\Delta x_b=\Delta t_b=h_b,\qquad c=1.
\]

原文件计算的 `viscosity,diffusivity,gBeta,Snu,Sq,Qk,Qnu,paraA` 均作为最细格距下的参数；全域共用原来的 `lengthUnit,timeUnit`。每个非守恒矩的松弛率满足论文式 (20)：

\[
h_b\left(\frac1{s_b}-\frac12\right)
=\left(\frac1{s_f}-\frac12\right),\qquad
s_b=\left[\frac12+\frac{1/s_f-1/2}{h_b}\right]^{-1}.
\]

流场的 `Snu` 与 `Sq` 均作这一换算；**不能只换剪切矩，也不能在粗块重新套细块的 `Sq(tauf)` 魔术参数公式**。温度场的 `Qk,Qnu` 同样换算。`paraA` 及热平衡矩在两级间保持相同。

因此下式在各块相同：

\[
\nu=h_b\frac13\left(\frac1{S_{\nu,b}}-\frac12\right),\qquad
\kappa=h_b\frac{4+A_T}{10}\left(\frac1{Q_{k,b}}-\frac12\right).
\]

当前 D2Q5 分支 (A_T=-2/3)，旧分支 (A_T=\mathrm{paraA})。块内每步的浮力增量使用 `h_b*gBeta`，`SideHeatedHa` 分支的每步磁场源系数也乘 `h_b`。各块的速度单位相同。

## 接口交换

代码使用**迁移后的分布函数**构造宏观量和矩。设 `Fm` 为尚未乘 `(I-S/2)` 的力矩增量，论文式 (19) 可写为块间公共量

\[
K_a=\frac{s_{a,b}}{h_b}\left(m_{a,b}-m^{eq}_{a,b}
                    +\frac12 F^{LB}_{m,a,b}\right).
\]

插值传递 `rho,u,v,T,Fx/h,Fy/h,Kf,Kg`。目标块按

\[
m_{a,d}=m^{eq}_{a,d}+\frac{h_d}{s_{a,d}}K_a
                         -\frac12F^{LB}_{m,a,d}
\]

重建全部非守恒矩。守恒矩直接恢复为

\[
m_0=\rho,\qquad m_3=\rho u-F_x^{LB}/2,\qquad
m_5=\rho v-F_y^{LB}/2,\qquad n_0=T.
\]

`EnableUseG` 的两个非守恒热流矩也有源修正。接口保留原离散历史，通过当前 (B=(uT,vT)) 与上次 `collisionT` 保存的 `B_prev` 定义

\[
D_B=(B-B_{prev})/h_b,\quad
R^{LB}_T=(0,h_bD_{B,x},h_bD_{B,y},0,0),\quad
B_{prev,d}=B_d-h_dD_B.
\]

`Kg` 的定义相应包含 `R_T^LB/2`。这是对原 D2Q5 离散修正及其分裂推进时序的适配；论文没有直接给出这个 `B_prev` 接口实现。纯导热和有限时间对照已覆盖基础正确性，更严格的时间/空间收敛阶仍需单独验证。

空间上区分两类目标：**重合节点直接读取同坐标来源节点的交换量**；非重合细节点使用四点 Lagrange 插值，二维采用张量积的 `4×4` 模板。随后均按目标块松弛率重建矩，不能直接复制跨级的原始 `f,g`。粗块从细块获取的人工边界节点必须全部重合，建连接时对此作显式检查。同级重合点也走直接读取路径。

来源节点或插值模板严格避开来源块两层人工边界。细块在每个子步碰撞前重建这两层，随后缓冲节点与内部节点一起碰撞、迁移；粗细同步时再重建两级边界，为下一步准备完整状态。新计算初始化也先交换一次；真实物理壁面仍执行原 BB/ABB。

时间上先得到粗块 (t+\Delta t_c) 的预测，细块执行 `refineRatio` 个子步。第 `k` 个子步先在起始时刻 `t+(k-1)*Δt_f` 补齐碰撞前缓冲数据，因此取 `θ=(k-1)/refineRatio`，三时间层 (t-\Delta t_c,t,t+\Delta t_c) 的权重为

\[
w_-={\theta(\theta-1)\over2},\quad w_0=1-\theta^2,
\quad w_+={\theta(\theta+1)\over2}.
\]

首个粗步缺少负时间层，采用线性启动；其后使用上述三时间层公式。所有细子步完成后，先从细块修复粗块人工边界并更新粗块预测快照，再用同步时刻的数据修复细块边界，最后滚动粗块历史。比值改变后仍保留三个粗块历史层，`nh=2` 表示数组下标 `0:2`，不应改为粗细比。插值先读固定的来源快照，再更新全部目标节点，避免块处理次序改变结果。

## 统计、输出与重启

所有体积分使用 `blockOwnedBox` 定义的物理分区。首先按节点控制区与分区的交集构造一维裁剪权重，再在末两个积分节点之间转移权重 `shift=((hi²-lo²)/2-sum(w*x))/h`：倒数第二个权重减去 `shift`，最后一个加上 `shift`。这样总长度不变，线性坐标积分也精确，并检查所有权重非负。接口落在细节点上时，细块边缘也可能需要修正。二维使用 `A_ij=dxWeight(i)*dyWeight(j)`，这些是数值积分权重，修正处不再逐项等同于原控制区的几何交集。远离边缘的内部权重仍为 `h²`：

\[
Nu_V=1+\frac{L}{\kappa\Delta T}
\frac{\sum_b\sum_{A_{ij}>0}u_\parallel T A_{ij}}{L_xL_y},
\quad Re_V=\frac{L}{\nu}
\sqrt{\frac{\sum_b\sum_{A_{ij}>0}(u^2+v^2)A_{ij}}{L_xL_y}}.
\]

例如中心块在 `[127.5,897.5]` 上使用 `127.5,129.5,…,897.5` 共 386 个积分节点，区间总长度为 `770`。其一维两端权重各为 `h/2=1`，内部权重为 `h=2`，无需一阶矩修正，等价于复合梯形积分；二维取两个方向权重的乘积。靠墙细块仍可能需要一阶矩修正。共址节点可以同时贡献相邻两块各自区域的端点积分，不代表重复计入同一片面积，也不能把每个样本都乘 `h²`。这种选择使中心权重更规整，但不预先保证实际 Nu/Re 的误差更小。

热壁、冷壁沿用原半步长壁面温度梯度公式；壁面和中线沿切向按裁剪长度加权。中线值及梯度在真实中线坐标处由四点多项式求得。稳态收敛误差也按面积加权。

- `NuRe_2DOpenaccMultiblock.dat`：实际 `t_ff,NuVolAvg,ReVolRMS,Nu_hot,Nu_cold,Nu_middle,mass,meanT,Tmin,Tmax,rhoMin,rhoMax`。
- `NuReStatistics_2DOpenaccMultiblock.dat`：指定时间窗和前/后半窗的平均值、相对差异；对 `Re²` 时间积分后开根号。时间窗覆盖不完整时明确输出 `INCOMPLETE`。
- `...Tecplot-*.dat`：ASCII 多 zone 格式，只写正面积积分节点；含物理坐标、局部格距和第八列 `integration_area/L^2`。原单块 `.plt` 二进制读取器不能直接读取这个格式。
- `...Snapshot-*.bin`：多块 stream 格式，16 字节 `MB2DSNAPSHOT0002` 标识（空格补齐），随后为 4 个 int32 `nBlocks,nx,ny,itc` 和 2 个 float64 `t_ff,lengthUnit`。每块依次写 2 个 int32 `ni,nj`，7 个 float64 `first_node_x,first_node_y,h,xmin,xmax,ymin,ymax`，再写一维 `dxWeight(ni),dyWeight(nj)`，最后按 Fortran 顺序写 `u,v,T,rho` 四个二维数组。坐标原点现在是首个积分节点，物理分区单独记录。
- `reloadFile2DOpenaccMultiblock-*.bin` 与 `-latest.meta`：完整保存各块 `f,g`、宏观量、力、`B_prev`、粗时间层、采样编号和输出编号。仅在粗细同步时写入，网格、算法、参数和历史样本数不匹配会拒绝重启。当前标识为 `MB2DRESTART0007`，增加独立的 `reloadFileNum` 计数，拒绝旧版本检查点。`blockBaseBox` 在初始化时由相同网格参数确定，重启核对实际节点尺寸、原点、格距和 `blockOwnedBox`；快照二进制结构仍为 v2，内含当前分区及权重。

**v1/v2 重启检查点均不兼容本版，需从初场开始。场快照结构保持 v2，已有 v2 快照读取器仍可用于后处理。** 本目录两个验证 JSON 和图示已按对齐后的源码重新生成。

输出时刻和最终目标时刻向上对齐到粗细同步步，时间列写实际时刻。时间间隔至少为一个粗步。检查点完整写完后才更新 `latest.meta`，旧编号检查点保留。续算可延长总目标时间，需同时保留对应的 Nu/Re 历史。

续算入口与原二维代码保持相近：`loadInitField=1` 时优先读取 `latest.meta`；仅该文件缺失时，使用手动设置的 `reloadFileNum` 查找 `<reloadFilePrefix>-<12位编号>.bin`。存在但无法读取或内容错误的 meta 会报错，不悄悄回退。二进制文件本身保存累计步数及全部输出计数，因此手动选择也不推断时间。`loadInitField=0` 会清零重启文件计数，不采用遗留的手动编号。

输出参数按原程序分别放在 `steadyFlow`、`unsteadyFlow` 两个分支：稳态采样间隔默认 `10 t_ff`，非稳态为 `0.5 t_ff`；两者的重启文件和 Tecplot 默认均为 `100 t_ff`。三个输出开关独立，关闭快照仍照常记录 Nu/Re。非稳态 `unsteadyRunDuration` 是绝对总目标，续算只补足剩余时间；三个平均窗口参数不改变推进时长。重启文件编号也采用原程序规则：非稳态按输出次数递增，稳态按累计细格子步命名；计数保存在检查点中，续算后继续编号。

原程序只适用于单块均匀网格的流函数/涡量、壁面极值五点拟合后处理未直接搬入本文件；当前提供上述适用于原生多块网格的输出。所有输出使用新的 `Multiblock` 前缀。
