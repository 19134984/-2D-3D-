# 多块网格：初始化、续算与独立后处理

本说明对应 `2DRBOpenaccMultiblock.F90` 与 `2DRBOpenaccMultiblockPostprocess.F90` 的新文件格式。均匀网格、ISLBM 基准源文件没有修改。

## 参数与初始化

`interfaceSkin=2` 保持两层接收节点。它位于网格参数区；粗网格松弛率由细网格参数和 `refineRatio` 在模块中直接确定。三个输出步数间隔和稳态检查间隔也在模块中确定，初始化只检查配置是否合法。

输出时间间隔必须为正。`ceiling(间隔*timeUnit/refineRatio)*refineRatio` 保证输出落在粗细同步步；非稳态累计目标进一步向上对齐到 Nu/Re 采样步。实际时间可能比所填 tff 稍大，应以历史中保存的实际时间为准。

初始化顺序为：集中检查、设置本次计数与坐标、分配五区及接口历史数组、设置初始场、可选恢复检查点、整理历史文件、计算剩余步数、记录设置和建立新历史标题。初始化中不再遍历所有节点验证总面积；Nu/Re、收敛误差和后处理仍使用按真实物理区域裁剪的积分权重。

`itc` 是本次步数；`reloadItcOffset+itc` 是累计步数；`NuReSampleCount` 是累计正式采样次数。`latticeUpdateCount` 统计本次节点更新次数。设置日志记录续算位置和本次累计目标。

## 左右周期边界

仍使用 `VerticalWallsPeriodicalU`、`VerticalWallsPeriodicalT`，分别控制流场和温度。开启时应关闭同一边的其他边界宏；程序会检查互斥条件。默认算例的宏没有自动改为周期。

四个细区全部碰撞后，在现有细区交换处额外复制左右最外侧的碰撞后分布到 `f_post/g_post` 的 `i=0` 和 `i=n+1` 列，再迁移。斜方向的 `j-1/j+1` 由迁移公式处理；上下角部越过水平壁面的分布由水平壁面条件最终赋值。原先在 `bounceback` 中从同一个局部数组另一端取值的周期分支已移除，避免覆盖结果。

单网格模式由本数组两端填入自己的迁移外圈。周期交换与中心粗细接收层不同，不改变 `interfaceSkin`、粗细转换公式或时间推进顺序。

## 检查点

每次保存一个数组文件，并覆盖唯一的元数据文件：

- `reloadFile2DOpenaccMultiblock-<tff>tff-<累计细步数>itc.bin`：只保存数组。
- `reloadFile2DOpenaccMultiblock-latest.meta`：直接保存格式标识、最新 bin 文件名、网格、模型开关、物理参数、输出间隔、累计计数、误差、各区几何；稳态另记录误差检查间隔。每组数据上方有说明。

不再生成各时刻的 `.meta`。先写完并关闭 bin，再覆盖 latest.meta。

正常续算设置 `loadInitField=1`，优先读取 latest.meta；文件存在时，其中的文件名和累计计数优先于手工设置。若内容损坏、参数不匹配或指定 bin 无法读取，直接报错，不转入手工分支。

只有 latest.meta 不存在时，才使用手工填写的 `reloadFileName` 和 `reloadItcOffset`。例如文件名为 `reloadFile2DOpenaccMultiblock-100tff-100000itc.bin` 时，填写 `reloadItcOffset=100000`。程序不解析文件名，需确保两者对应。累计细格子步数必须非负且为 refineRatio 的整数倍；`reloadDimensionlessTime=reloadItcOffset/timeUnit`，`NuReSampleCount=reloadItcOffset/outputSnapshotIntervalItc`，时间不需要手工填写。初始化仅在重新计算时清零累计步数；续算时保留手工值，有 latest.meta 则以其中的值覆盖。文件名中的 tff 用于查看，不用于反推恢复步数。

手工分支没有旧元数据可用于核对模型、网格和输出间隔，因此必须使用相同设置生成的 bin。稳态的 up/vp/Tp 仍从 bin 恢复，但 errorU/errorT 保留初始值，直到下一次 check 更新。reloadMetadataLoaded 仅在成功读取元数据时为 true。恢复本身不生成 meta；下次保存检查点才写 latest.meta。若在此前再次中断，仍使用相同手工设置续算。

bin 的顺序为 coarse、left、right、bottom、top。每区依次为 `f,g,u,v,T,rho,Fx,Fy`；粗区后面还保存三个接口时间历史；稳态每区再保存 `up,vp,Tp`。每个完整数组内部为 i 最快、j 其次、分布方向最后。迁移临时数组不需要保存。

有 latest.meta 时，先核对全部元信息，再恢复数组。累计步数必须非负并为 `refineRatio` 的整数倍。总目标只记录，不要求等于旧目标；增大 `unsteadyRunDuration` 后只运行剩余步数。模型、物理参数及固定采样间隔仍需保持一致。

不兼容旧二进制格式或旧的 latest 指针文件，也不通过文件名反推步数。

## 历史回退与旧输出清理

Nu/Re 历史列为：

```
sample itc_total t_ff NuVolAvg ReVolRMS Nu_hot Nu_cold Nu_middle mass meanT Tmin Tmax rhoMin rhoMax
```

稳态每次 check 只写一份收敛历史：

```
itc_total t_ff errorU errorT
```

例如检查点在 100 tff，历史写到了 130 tff：先读取并验证检查点对应的历史前缀到内存，关闭文件，再用 `status='replace'` 写回标题和保留记录。后续用 append 写下一次采样。检查点之后的旧尾部直接删除，无备份或临时历史文件。若所需前缀缺失，则报错；不能凭检查点补出过去的采样。

`OutputFiles_2DOpenaccMultiblock.dat` 是很小的文本索引，每行是准确累计步数和程序生成的文件名。续算依此删除检查点之后的快照、plt 和最终诊断文件，并重写保留的索引。删除范围限定当前目录内本算例的输出前缀，不扫描或递归删除目录；不依赖 tff 文件名的舍入。旧检查点 bin 仍保留；手工恢复旧位置时，需要在没有 latest.meta 的情况下填写其文件名和累计细格子步数。

索引也用于后处理选择有效快照。新算例重建索引，后处理只读取索引列出的快照，不通配整个目录。建议不同算例使用独立运行目录。

## 快照和最终结果

快照命名为 `<snapshotFilePrefix>-<tff>tff-<累计细步数>itc.bin`，plt 命名为 `<pltFolderPrefix>-<tff>tff-<累计细步数>itc.dat`，与重启文件采用相同的时间和步数后缀。tff 保留十二位小数后去掉末尾零，仅用于查看；整数步数保证不同保存步的文件名不同。

续算检查已有快照、plt 时，使用同一规则构造完整文件名。输出索引保存完整名称，旧输出清理和后处理直接使用索引中的名称，不解析文件名，也不由 tff 反推步数。

GPU 数据先同步到主机。同一同步步内只传一次宏观场；保存完整检查点时再补传分布函数、力和接口时间历史。

快照将约定输出范围内的原始节点按 coarse、left、right、bottom、top 拼接为 `uall,vall,Tall,rhoall`，每段 i 最快、j 其次。中心不输出接收层；四个细区保留完整矩形节点，后处理剔除零积分面积的接口节点。不会插值为全域均匀网格。

二进制快照采用流格式：

1. 16 字节字符 `MB2DSNAPSHOT0001`；5 个四字节整数：块数、nx、ny、累计步数、热驱动方向（0 上下，1 左右）。
2. 8 个双精度实数：tff、lengthUnit、viscosity、diffusivity、Thot、Tcold、Tref、timeUnit。
3. 中心积分矩形的 4 个双精度实数。
4. 每块 2 个整数（ni、nj）和 3 个双精度实数（首节点 x、首节点 y、dx）。
5. 四个完整拼接数组 uall、vall、Tall、rhoall，均为双精度原始格子场。

不保存逐节点面积、面积行或一维积分权重。后处理由块几何和中心矩形重建面积。

稳态退出时主程序仍输出独立的 `FinalNuRe_2DOpenaccMultiblock.dat`，记录实际累计步数、是否收敛和最终 Nu/Re，不增加正式采样计数。到最大步数但尚未收敛时，标志为 false。最终快照、plt、检查点按原开关补存；同一步已有相应输出时避免重复。

## 独立后处理程序

`2DRBOpenaccMultiblockPostprocess.F90` 可独立编译并在结果目录运行，不依赖 OpenACC、GPU 或求解器模块。开头参数区设置：

- `postprocessSteady=0/1`：非稳态/稳态。
- `unsteadyAverageStartTf/EndTf/MidTf`：非稳态统计窗口。
- `processSnapshots`：是否读取快照重算瞬时空间指标。
- 输入历史和索引文件名。

物理参数及几何从快照读入，不必再填写一套。求解器末尾不再调用非稳态窗口统计。

输出包括：

- `NuReCurve_...dat`：通过连续性检查的绘图用采样数据。
- 稳态：`ConvergenceCurve_...dat` 与 `SteadySummary_...dat`，不做时间平均，保留独立最终结果及收敛标志。
- 非稳态：`NuReStatistics_...dat`，给出整个窗口、前半、后半的统计和相对差异。Nu 做时间积分平均，时空 RMS Re 对瞬时空间 RMS 的平方积分后开方。窗口未覆盖时明确输出 INCOMPLETE，不给出最终均值；缺失采样直接报错。
- `SnapshotNuRe_...dat`：按索引读取快照，用与主程序相同的面积、壁面及四点中线公式重新计算指标，包含最后一个非周期采样时刻的快照。

后处理不会覆盖求解器的场数据或原始历史。绘图文件是普通文本，可以在已有绘图工具中直接读取。

Windows 可使用仓库的 `运行脚本/build_in_ascii_path.ps1` 编译后处理源文件；gfortran 需要 `-ffree-line-length-none`，不需要 OpenACC 标志。运行可执行文件前，将工作目录切换到算例结果目录。

## 验证范围

可重复运行 `运行脚本/tools/verify_multiblock_restart_postprocess.py`。脚本只在新临时目录生成小网格算例，不操作已有算例数据。需要 gfortran 和 Python/numpy，可用 `--compiler` 指定编译器；可选 `--before` 指向修改前源文件进行数值对比。

已检查：Fortran/OpenACC 语法；壁面、多块周期、单块周期、分别开启速度/温度周期、粗细比4、侧壁差温和稳态小算例；周期逐方向映射及角部；提前检查点恢复、历史尾部删除、延长累计目标；快照体积与独立重算一致性；窗口平均解析数据和缺测检测。OpenACC 指令在 gfortran 主机设备上运行，与 CPU 参考数组一致。

这些是功能回归与数值一致性检查，不代表高Ra统计收敛、网格无关性或NVIDIA GPU性能验证。尚未进行 NVHPC/P100 实测。
