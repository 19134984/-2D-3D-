# 2DRB目录与工作总览

盘点日期：2026-10-24。根据当前源码、实际目录和已保存结果整理。本次没有修改求解器或提交计算。

`2DRB` 是整个热对流代码工作区，内部同时包含二维、三维以及CPU/GPU/MPI版本，不是只有二维RB程序。侧壁加热与上下加热RB也同时存在；具体工况由各源码宏和参数决定。

## 六个主要计算方向

| 目录 | 研究目标、已有工作 | 当前主源码 |
|---|---|---|
| `均匀网格/` | 常规规则网格热对流程序；二维/三维、OpenMP、OpenACC及MPI移植，是其他方案的基线家族 | 9份Fortran；包括`2DRBOpenmp.F90`、`2DRBOpenacc.F90`、`3DRBOpenmp.F90`、`3DRBOpenacc.F90`及相应MPI版本 |
| `ISLBM/` | 插值补充LBM，在非均匀网格上进行迁移与插值，做二维/三维及CPU/GPU/MPI实现对齐；与多块粗细时间步交换属于不同路线 | 8份Fortran；如`2DRBOpenaccISLBM.F90`、`3DRBOpenaccISLBM.F90`、`3DRBOpenaccMpiISLBM.F90`；两个OpenMP-MPI文件名已标注不再重点检查 |
| `STLBM/` | 简化热LBM路线；当前分支直接推进宏观变量，f/g作为平衡态与非平衡项临时缓存，而不是持续演化状态 | `2DRBOpenmpSTLBM.F90`、`2DRBOpenaccSTLBM.F90` |
| `Xs/` | 带χ参数的LBM-CDE及TRT稳定性研究；比较三种温度离散模型、流场松弛参数和高Ra行为 | 下列三个子目录各有一份二维OpenACC求解器 |
| `PTRT/` | P-TRT净化流场幽灵模态，并与守恒一致的Guo/MRT体力、Luo/Wang温度场配套；保存代数检查、短程回归及P100侧热测试 | `2DRBOpenaccPTRT.F90` |
| `多块网格/` | 当前主要研究线：中心粗格、四周细格、粗细子步交换、接收层、面积积分、GPU实现、续算和Nu/Re；进一步做反算、正则化和分区χ试验 | `2DRBOpenaccMultiblock.F90`；配套`2DRBOpenaccMultiblockPostprocess.F90` |

四个正式核心基线按`AGENTS.md`为：`均匀网格/2DRBOpenmp.F90`、`3DRBOpenmp.F90`、`3DRBOpenacc.F90`、`3DRBOpenaccMpi.F90`。做二维GPU改动时，仍需结合已有二维OpenACC源码核对数值及GPU风格。

### Xs中的三个温度分支

| 子目录 | 温度模型 | 主要区分 |
|---|---|---|
| `D2Q9TRT_D2Q5LuoTRT/` | Luo/Wang D2Q5 TRT温度场 | 用传统五速度温度模型作对照 |
| `D2Q9TRT_D2Q9BGK/` | D2Q9 BGK温度场 | 九速度、单松弛温度模型，带χκ修正 |
| `D2Q9TRT_D2Q9TRT/` | D2Q9 TRT温度场 | 九速度、固定温度松弛率，通过χκ、ce、paraA匹配热扩散 |

三份当前源码均保留流场`FLOW_ODD_ORIGINAL_MAGIC`、`FLOW_ODD_EFFECTIVE_MAGIC`、`FLOW_ODD_FIXED_SQ`和`FLOW_BGK`的互斥选择，当前默认启用原始magic。因此，不能根据文件名含TRT就认定某个历史提交一定使用TRT；历史BGK运行应核对各自冻结源码。

这里的全域均匀网格χ实验，与多块“细χ=0、粗χ=0.5”实验不是同一份求解器。多块实验仍作为独立副本保留。

### PTRT的实际验证记录

`PTRT/README.md`的早期段落记录了移植与主机检查，不能代表后续测试没有进行。`PTRT/p100/`还保存了侧壁加热Ra=10⁶、10⁷、10⁸实测：前两组当时快照达到稳态收敛，10⁸对应512²配置早期检出非数。查看`PTRT/p100/Ra1e7_Ra1e8_结果核查_20260919.md`及Ra6独立报告。不能把这些历史记录当成当前所有参数已验证。

## 多块网格这条线上做过的工作

1. **主程序整理与GPU修复**：从均匀与ISLBM基线派生；简化参数、紧凑存储、明确接收层与积分范围；处理P100运行问题、输出和精确续算。
2. **侧壁稳态基准**：Ra=10⁶、10⁷、10⁸，细级等效1024²，与文献四指标比较。
3. **非稳态RB基准**：Ra=10⁶至10¹⁰；保持历史/快照输出，采用指定窗口计算Nu和时空RMS Re；Ra6小扰动重算与原双涡结果分开保存。
4. **粗网格及接口诊断**：原始缩放、仅流场反算、仅温度反算、联合反算、单层粗参数对照、周期扰动谱、参考解接收层、插值和F2C隔离等。
5. **正则化试验**：PR2、RR3、H-RR及边缘处理；Ra8四组完成1000 TFF，高Ra另做分辨率和长期稳定性测试。
6. **替代算法试验**：双D2Q9-BGK的LBM-CDE、粗细分区χ，修正该分支九方向温度halo并做续算验证。
7. **成果汇合**：原两棵工作树成果进入当前主目录；轻量报告和关键冻结源码进入main，大型原始数据继续本地/服务器保存。

最近两组均已完成累计1000 TFF：Ra8多块细512²分区χ方案Nu/Re误差约0.098%/0.624%；Ra9多块细2048²的RR3方案约7.17%/4.13%。完成时长不代表Ra9精度问题已解决。

## 其余目录的分工

| 目录 | 内容与用途 |
|---|---|
| `基准代码/` | 原始参考实现`thermal2Dcell-omp.F90`，用于核对标准侧热方腔公式及结构；不是当前全部派生方案的替代入口 |
| `后处理/` | 旧均匀网格Nu/Re序列处理、统计、历史合并、MATLAB画图、χ扫描及旧提交脚本；不同文件对应不同输入格式，不能直接替换多块专用后处理 |
| `运行脚本/` | PBS、运行脚本、本地编译助手、服务器提交和续算组织 |
| `运行脚本/tools/` | 生成算例、核对Nu/Re、检查续算、整理结果等辅助脚本 |
| `运行脚本/run_cases/` | 每批实验的源码快照、参数、PBS、日志和核验证据；是实验档案，不是统一的新主代码目录，按既有规则不进Git |
| `references-code/` | btLi的OpenACC并行结构对照，以及zzhao的自然对流、RB、Poiseuille、GPU/MPI参考代码；供比较，不自动视为已验证主程序 |
| `TRT零基础推导/` | 基础LBM、BGK到TRT、边界magic、温度四阶误差、参数映射和练习；含论文证据、SVG、公式复算、最终Markdown/PDF，是理论教程 |
| `文档/` | 参数推导、文献核查、数值交接、服务器操作说明、合并记录和最新报告；`最终成果/`内为正式推导稿和PDF；少量冻结源码作为证据存档 |
| `pdf/` | 原始论文，包含ISLBM、LBM-CDE、热LBM、多块、P-TRT和RB耗散统计等 |
| `tmp/` | 论文提取文本、临时图片和预览缓存；不作为正式验证结论来源 |
| `.agents/`、`codex-skills/`、`AGENTS.md`、`skills-lock.json` | 助手操作规范与技能配置，供开发使用，不参与数值推进 |
| `.fortls`、`.gitignore`及Git相关目录 | 编辑器与版本管理配置，不是数值算法 |

## 使用时从哪里开始

- 改通用均匀网格程序：`均匀网格/`。
- 改当前多块算法：`多块网格/2DRBOpenaccMultiblock.F90`；新实验继续用副本。
- 查多块实验算法：`运行脚本/run_cases/`及合并报告里的来源清单。
- 查最终定量结果：`文档/两组长算结果_20261024/`与两份前期测试总表。
- 了解TRT、magic及温度参数推导：`TRT零基础推导/05_最终报告/`。

目录中同时包含成熟基线、实验实现及历史记录；源码存在、完成短测、完成1000 TFF、统计收敛、文献吻合、网格无关分别是不同状态。部分旧README反映早期阶段，具体算法开关以当前源码或历史运行冻结源码为准。
