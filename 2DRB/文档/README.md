# 文档目录说明

本目录集中保存 2DRB 项目的研究说明、推导报告、文献证据和最终交付成果，
不存放主求解器源码或临时运行数据。

## 根目录文档

- `high_ra_derivation_source_matrix.md`：高 Rayleigh 数稳定化推导的来源与任务对应表。
- `high_ra_lbm_derivation_completion.md`：高 Rayleigh 数 LBM 稳定化推导的完成稿。
- `lbmcde_p100_2d_literature_evidence.md`：LBM-CDE 与二维高 Ra DNS 的文献证据核对。
- `lbmcde_p100_2d_tau_lattice_report.md`：LBM-CDE/TRT 参数推导及 P100 验证总报告。
- `lbmcde_poiseuille_low_viscosity_grid_report.md`：Poiseuille 边界漂移测试报告。
- `zhang2017_dissipation_benchmark_requirements.md`：Zhang 等（2017）耗散统计基准要求。

## 最终成果

`最终成果/` 保存适合直接阅读或交付的完整推导稿、PDF，以及生成 PDF 所需的
Markdown、LaTeX 和分章节源文件。这里的文件属于正式成果，不是临时缓存。

主求解器仍位于 `均匀网格/`、`ISLBM/`、`STLBM/` 和 `Xs/`；原始论文位于
`pdf/`。
