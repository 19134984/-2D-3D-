本次只整理本地已有记录，没有重跑算例或修改求解器。旧版同日期交接报告已替换为本文内容，附件也按本版重新整理。

## 2. 测试中用过的算法改动

以下仅用于辨认各算例使用了什么，没有把任何一种修改写成问题原因或解决结论。

| 名称 | 实际修改内容 |
| --- | --- |
| 原始多块方案 | D2Q9 TRT流场＋D2Q5 Luo温度；粗区按原关系缩放流场和温度的松弛参数，paraA保持原选择。 |
| 标准均匀参数 | 按该均匀网格自身的分辨率构造流场魔法参数及Luo温度参数，没有粗细接口。 |
| 搬入粗／细区参数 | 把指定多块某一级的参数放进同格距的全域均匀网格；参数来源在表中列明。 |
| 仅流场反算 | 控制黏度的参数仍按粗细比缩放，另一组TRT参数按魔法参数3/16反算；温度保持原方案。 |
| 仅温度MRT反算 | 保留paraA及扩散参数缩放，将两个高阶温度矩松弛率分别反算；粗区温度使用MRT。 |
| 联合反算 | 同时采用上述流场反算和温度MRT反算。 |
| 恢复标准均匀温度 | 改回该均匀网格自身的Luo温度参数；与保留原paraA的温度MRT反算分开记录。 |
| PR2 | 流场采用二阶正则化；温度仍为原D2Q5 Luo方案。 |
| RR3 | 流场采用三阶递归正则化；温度仍为原D2Q5 Luo方案。 |
| H-RR3 | 流场采用混合递归正则化；分别测试σ=0.98、σ=0.90及块首末两层改用RR3的版本。 |
| EnableUseG | 改用均匀核心已有的D2Q5温度分支，包含Tu时间修正及配套接口历史。它不是温度MRT反算。 |
| 分区χ | 另一个双D2Q9、双BGK的LBM-CDE副本；细区χ=0，粗区分别取0.5、0.8、0.9。流场和温度均改变。 |
