# 多块网格与均匀网格：全部测试结果及误差

整理日期：2026-10-23（北京时间）。范围为本次对话中2026-10-19至2026-10-22开展、且有可核对记录的正式计算与诊断试验。主代码未因本次整理而修改，也未提交新作业。

共整理145条求解运行记录和92项扰动测试。求解记录含重复复现、不同采样协议、短测及续算，不是同数量的独立正式算例。编译失败、未通过驱动核验及未启动的计划在附录单列，不算物理发散。

## 1. 读表口径

- 多块“细512²／粗256²”均按全域长度除以格距折算；不是中心粗块数组197²。粗细比均为2。细128/256/512/1024/2048对应的标准中心粗数组（含2层接收层）依次为53/101/197/389/773。扩大细区和4层接收层的例外在逐项表注明。
- 侧壁加热：Pr=0.71；RB：Pr=0.7。热对流算例Ma=0.1。无浮力扰动试验没有实际热驱动Ra，其松弛参数来自Ra=10^8母算例，不能冒充Ra=10^8完整热对流验证。
- “稳态收敛”仅指errorU、errorT均达到1e-7；“完成1000 TFF”指非稳态目标完成；“通过短测”只说明相应有限窗口通过。三者分开记录。
- 失稳时间均为对应检查协议检出无效状态的时间，并非连续时间的精确起点。0.5 TFF检查、加密阶段探针、每步检查的时间不能直接用来评价改善百分比。
- 稳态Re采用空间RMS；RB统计采用sqrt(时间平均(瞬时空间RMS Re²))。RB Nu为时间平均。误差=100×|计算值−文献值|/|文献值|。
- 稳态参照ISLBM论文表2 Present 1025²行。按此前讨论保留RMS Re与表中数值的比较；原文速度定义的疑义仍保留，不认定排印错误已被证明。RB参照Zhang、Zhou、Sun（2017）JFM814表1、Pr=0.7。
- 未收敛、失稳、参考值强制替换和无浮力试验，不给正式稳态或RB文献误差。Ra6的原双涡分支虽然完成统计，但单独保留，明确其与参考分支不符。

## 2. 算法名称及区别

| 名称 | 具体含义 |
|---|---|
| 标准均匀原生参数 | 在本均匀网格上直接构造流场魔法参数及Luo温度特殊TRT；不含粗细接口。 |
| 原始全部缩放 | 细区保持原关系；粗区所有相关平移松弛时间按粗细比缩放。 |
| 仅流场反算 | 控制黏度的参数仍缩放，非粘性奇矩由魔法参数3/16反算；温度不变。 |
| 仅温度MRT反算 | 控制扩散的参数及paraA保留原缩放选择，两个温度高阶矩由四阶误差消去关系独立反算；粗区温度变为MRT。 |
| 联合反算 | 同时采用上面流场魔法参数反算与温度MRT反算。 |
| 匹配粗区参数的均匀单块 | 去除接口，将指定多块粗区整套参数放到对应粗格距均匀网格；不能与标准均匀原生参数混称。 |
| 恢复标准温度参数 | 恢复该均匀网格自身的Luo温度参数族；与保留原paraA的温度MRT反算不同。 |
| 粗区奇矩松弛率设为1 | 另一个耗散诊断选择，不是魔法参数反算；碰撞和接口同时使用新松弛率。 |
| PR2 / RR3 / H-RR3 | 全流场正则化方向，已改变高阶模态处理；不再是原TRT全部缩放。温度算法保持原路线。H-RR为含已记录梯度/边缘简化的适配，不声称完整复现文献。 |
| 参考值替换 | 用同步均匀细网格数据强制细区接收层，是定位通道的诊断边界；不是可独立使用的正常多块算法。 |

## 9. 汇报时可以使用的结论

1. 侧壁加热Ra8：标准均匀128²、256²、512²均达到稳态阈值；原始多块细512²／粗256²和细1024²／粗512²收敛，继续粗化为细256²／粗128²及细128²／粗64²则失稳。
2. 原多块粗区参数搬到均匀网格也可能失稳，说明问题不只来自接口；联合反算能让参数匹配的均匀128²、256²收敛，却未能稳定相应多块。
3. 粗区奇矩松弛率设为1配合参考接收层可算1000 TFF，但恢复正常双向耦合仍失稳。这是隔离证据，不能作为完整多块算法已经稳定的结果。
4. RB原始算法完成Ra6/7；Ra6原双涡分支与文献偏差大，加小扰动从零重算后Nu/Re误差约0.24%/0.36%。原始Ra8/9/10失稳。
5. 全流场PR2、RR3和两种H-RR方案在RB Ra8完成1000 TFF，Nu/Re文献误差均小于1%；相同候选在Ra9/10仍失稳。不能把“原始/反算路线未解决”概括为“所有改法都失败”。
6. 尚未完成唯一根因、严格跨接口收支、网格无关性及更长统计充分性的证明。当前证据属于数值稳定性及碰撞/接口耦合问题；没有显示Nu/Re时间平均后处理是失稳原因。
