# Wei 2015：原文公式、补全来源与项目扩展

魏文为 *Computers & Fluids* 118（2015）167–171，[DOI](https://doi.org/10.1016/j.compfluid.2015.06.003)。直接抽取5页正式PDF，渲染复核第2页（期刊168页）式(1)–(9)。

## 1. 原文可确定部分

式(1)、(2)的排版括号没有把完整平衡—非平衡差明确包在分母内；这里按其 BGK 碰撞语义修复为 `(feq-f)/tau`，不逐字照抄错误括号。

```text
f_i(x+c_i,t+1)=f_i+(feq_i-f_i)/tau_f+Fi
g_i(x+c_i,t+1)=g_i+(geq_i-g_i)/tau_g
Fi=3*wi*rho*gBeta*T*c_iy
rho=sum_i f_i, rho*u=sum_i c_i*f_i, T=sum_i g_i
```

D2Q9 方向和权重采用标准静止4/9、轴向1/9、对角1/36。力为显式线性项，没有速度依赖项、没有松弛率前因子；宏观速度不加半步力。若只把其中一个环节替换成 Guo 或 Luo，会变成另一种模型。本实现不作该替换。

坐标定义 y 向上，式(3)对应正向热浮力；原文宏观式(6)重力向量的符号约定并未完整展开，这里明确使用微观式(3)。温标取0至1，源项直接 T，不改为 T−0.5；这保留了常数背景势力，压力／密度初始调整与采用参考温差的代码可能不同。

## 2. 平衡态与物性是有引文支持的补全

魏文仅说明 feq/geq 是多项式，未给全部系数，也未重印物性关系。其参考文献[10]是 Shan，*Simulation of Rayleigh-Bénard convection using a lattice Boltzmann method*（1997），[作者预印本](https://arxiv.org/pdf/comp-gas/9612001)。该预印本PDF第4页式(2)给出二阶平衡态，第5页说明各组分使用相同平衡形式；第6页式(7)给出黏度，第7页式(10)在无温度组分相互作用 G22=0 时给出扩散关系。因此补全为：

```text
feq_i = wi*rho*[1+3ci.u+4.5(ci.u)^2-1.5u.u]
geq_i = wi*T  *[1+3ci.u+4.5(ci.u)^2-1.5u.u]
nu=(tau_f-1/2)/3, kappa=(tau_g-1/2)/3, dx=dt=1
```

这是魏文引用来源支持的明确选择，不等于作者未公开代码已被唯一恢复。Shan 自己的力离散使用速度偏移／半步定义，**没有**一起移植到这里；魏文有其明确式(3)、(4)，应保留魏文的显式源与原始速度。

## 3. 项目框架和边界补全

主框架仍是既有二维核心的 `initial/collision/collisionT/streaming/bounceback/streamingT/bouncebackT/macroT/macro`，两个碰撞用同层宏观场。魏文仅给方法简述，未定义半程墙面、角点、重启、采样和 Nu/Re 时间平均。

本项目用半程无滑移反弹、恒温 ABB、绝热镜面；恒温角点优先。二维格心范围1:nx／1:ny，壁面在半格处。初始f为标准平衡分布、初始u=0，不加半步补偿。初温线性并在 RB 中加入确定性小扰动，这是项目明确初值；没有复现魏文未细报的压力初始化或逐级升 Ra 流程。

原文第一算例为800×400周期通道，第二为1000²封闭方腔，后者仅明确上下温度；当前默认封闭方腔 RB 的侧温绝热是补全，侧热方腔是新增项目验证，不能称为同一原文算例。未添加周期生产模式或多块网格。

## 4. Nu/Re 与验证边界

按原文式(9)，RB体积 Nu=1+H〈vT〉/(kappa*DeltaT)；侧热以水平 u 和对应长度类推。瞬时空间 RMS Re、实际时间积分、快照和续算延续项目定义，未从魏文没有给出的统计窗口推造参数。

本地四宏编译、逐方向公式／矩检查、导热、短程完整推进、断点续算、周期小振幅输运以及低 Ra 侧热通过，仅支持所测实现路径。低 Ra 侧热体积Nu相对参考约0.195%的余差，不能确定全部源于强迫离散；未发现后处理或并行装配错误。

原文报告到Ra1e10快照并声称更高范围，但没有给出高 Ra 网格无关、长时间Nu/Re、边界层解析度或 GPU 性能数据。本实现没有高 Ra／DNS或实际 NVIDIA GPU 验收结果，不把原文展示自动转移为当前代码验证结论。
