# Feng 2026 温度算法与本实现的对应

来源为 arXiv:2605.01774v1，39页。核对正文式(7)–(41)、附录B；关键公式页为PDF第7、8、36页。本文区分论文定义、数值等价求值和项目适配。

## 1. 温度碰撞

当前采用标准D2Q9方向：0静止，1东、2北、3西、4南、5东北、6西北、7西南、8东南；权重4/9、1/9、1/36，`cs2=1/3`。只实现常系数各向同性扩散 `D=kappa I`。

式(7)：

```text
geq_i = T W_i [1+(c_i.u)/cs2+(c_i.u)^2/(2 cs2^2)-u.u/(2 cs2)]
T = sum_i g_i
j = sum_i c_i (g_i-geq_i)
P_i(a) = W_i (c_i.a)/cs2
ds_i = P_i(j)
dh_i = g_i-geq_i-ds_i
S = s I, s = (1/2+kappa/cs2)^(-1)
ds_post_i = P_i((I-S)j)
```

这对应式(9)–(19)、(34)。`dh`为零质量、零一阶矩部分，通量由`ds`承载。

式(38)–(39)：

```text
C = sum_i dh_i log(geq_i/W_i)
lambda = 1 + [sum_i dh_i ds_post_i/geq_i + C] / [sum_i dh_i^2/geq_i]
Omega_i = -P_i(S j)-lambda dh_i
```

原文所有数值计算使用该对数展开表达式，并没有指定`lambda in [0,2]`的裁剪，也没有使用逐格Newton极小值求解。本代码按此实现；与已存在的Frapolli程序不是同一个碰撞核。

### 稳定的数值求值

核内先以`phi=sum(g)`归一化population，等价地计算无量纲`p=g/phi`及对应的平衡态／非平衡分解，最后将碰后结果乘回`phi`。式(38)的比值对正比例缩放不变。

由于`sum(dh)=0`和`sum(c_i dh_i)=0`，可从式(39)的对数中减去常数和关于`c_i`的一阶项。代码用

```text
log(geq_i/(phi W_i)) - (c_i.u)/cs2 + u.u/(2 cs2)
```

求同一个`C/phi`。当速度小，用`log(1+x)-x`的收敛级数消除一阶项抵消误差；这保留了ADE修正，未把C置零。该代数等价依赖ghost零矩，独立测试需检查实际离散矩和公式值。

原文只规定`dh identically 0 -> lambda=1`。实现以归一化ghost的最大绝对值不超过`64*epsilon(real8)`视为机器零；该保护避免平衡态舍入余量被除以其平方后放大，不作为可调物理过滤强度。

## 2. 正支回退

式(40)的正阈值原文未给具体数值。本实现选择局部正阈值

```text
epsilon_local = max(tiny(real8), fengPositivityFloor*min_i p_i), p=g/sum(g)
alpha = min(1, min_{Omega_i<0} (p_i-epsilon_local)/(-Omega_i))
```

若发生回退，alpha再乘`1-16*epsilon(real8)`，避免落在正支端点时舍入成零。最终严格按式(41)将**整个**碰撞增量乘同一alpha：`gpost=phi*(p+alpha*Omega)`，不只缩放ghost；不再裁剪各方向分布或重设温度。

若输入温度／population／平衡态不是有限正值，或无法得到有限正碰后状态，记录持久失败标志并在检查／采样边界报错停止。设备核复制输入仅用于让错误能被安全诊断，不是恢复正常计算或修复失稳。

alpha小于1时，物理通量率也变为`alpha*S`。冻结该局部系数时，对应扩散率一般不再等于目标kappa。因此累计回退次数、最小alpha和lambda极值属于必要诊断；本实现不声称无条件稳定、全局H定理或回退后输运系数严格不变。

## 3. 流场与力

原文RB只给宏观Boussinesq方程，没有完整定义流场LB碰撞和力源。按用户选择，流场使用现有Luo/Wang D2Q9 MRT；`s_e=s_epsilon=s_nu`、奇矩`s_q=8(2*tauf-1)/(8*tauf-1)`，其余为核心基线的矩变换和Guo型力。

项目使用`Fy=rho*gBeta*(T-Tref)`，原文式(102b)使用相对于导热剖面的温度。不可压宏观层面两者差一个可归入压力的竖向势梯度，但离散初值和短时瞬态不同；这里保留项目已有约定，没有声称逐项重现原文RB。

两个碰撞读取同一时刻的T及物理半步速度。流场、温度迁移和壁面之后，先恢复T，再根据新rho／新T恢复下一步的物理速度；初始化f含半步力补偿。核心旧程序的macro使用collision保留的旧时刻Fy；此处的推进与初始化修正也属于相对旧程序的变化，不能声称只有温度碰撞的逐步差异。温度没有额外加入FPC、useG、热源或独立滤波。

## 4. 正温标、壁面与几何

对数熵要求正population；默认`Thot=2,Tcold=1`，Nu和浮力使用真实壁温差及`T-Tref`。当冷壁为0，半程边界附近的线性导热离散分布本身可能出现负值，不能简单照搬其他模型的零／负温标。

由于目标温度式是`dt(T)+div(Tu)=div(kappa grad T)`，有限网格速度散度非零时，恒定背景温度平移的数值等价性并非自动成立。不要把正温标选择等同于离散温标严格不变的证明。

原文没有population级边界公式。这里沿用项目半程无滑移、恒温ABB与绝热镜面；恒温角点优先。ABB可能破坏正性，需由场检查明确检测，不能靠碰撞回退声称整步保正。

默认侧热是封闭方腔；RB也是封闭方腔，上下恒温、左右绝热。原文RB则为长高比2、水平周期，Pr=1、Ra=1e9。本程序可独立验证各向同性温度碰撞，但默认生产算例不是该原文图表的同一几何。

## 5. 诊断、续算与精度边界

Nu/Re、壁面极值及后处理保持二维核心的定义；温度稳态变化按实际壁温差归一化，防止正背景温标降低名义误差。质量、回退计数和当前场正性另行检查。

严格续算除了f/g，还保存逐格回退计数、alpha最小值及当前熵状态；稳态保存上一次检查的宏观参考场和误差，不能在续算点重新置零。采样时间仍按绝对累计步数，后处理读取整个Nu/Re历史。熵历史逐行与Nu历史的样本步数对齐，并校验时间、诊断值和总行数，拒绝缺失或超前的诊断记录。

本地公式、输运和小网格检查只能支持相应离散实现正确性。高Ra稳定窗口、统计收敛、热预算一致性、实际NVIDIA GPU执行及网格无关性需分别验证；没有加入LES，不等于已经完成DNS精度验证。
